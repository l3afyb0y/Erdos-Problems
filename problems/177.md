# Erdős Problem #177

**Database status at attempt:** OPEN (checked 2026-08-30)

**Final classification:** no progress / simultaneous residue-subsequence balancing barrier

## Statement

Find the smallest `h(d)` for which there exists one colouring `f:N->{-1,1}` such that every finite arithmetic progression of common difference `d` has discrepancy at most `h(d)`.

Current status source: https://www.erdosproblems.com/177

## Exact representation

For a fixed difference `d`, every progression is an interval in one residue subsequence

`f(r), f(r+d), f(r+2d), ...`.

Thus the requirement for that `d` is exactly that every one of the `d` residue subsequences modulo `d` have uniformly bounded interval discrepancy. The global problem asks for a *single* sign sequence that has this bounded-interval property simultaneously for every modulus `d`, with the best possible dependence of the bound on `d`.

This makes the dependency obstruction explicit. Balancing the residue subsequences for one modulus does not tensor monotonically into another modulus: if `e=md`, an `e`-progression is a sparse subsequence of a `d`-residue sequence, and bounded discrepancy on intervals gives no bound for such sparse arithmetic subsequences.

## Discovery attempt

I tried hierarchical binary and divisor-recursive constructions. The tempting induction is to balance each residue class modulo a new modulus while preserving all earlier modulus constraints. The failure is structural: a local sign flip used to repair one new residue subsequence changes infinitely many sparse subsequences belonging to earlier common differences. There is no evident monotone invariant saying that discrepancy control for divisors propagates to multiples or conversely.

I also tested natural digital candidates (including Thue-Morse-type recursion) as possible low-complexity witnesses. They fail badly for odd common differences: finite scans show discrepancy growing rapidly rather than remaining bounded. These tests are falsification only and make no universal claim.

## Known frontier

The database records Cantor-Erdős-Schreiber-Straus's factorial-type upper bound, Beck's `h(d) <= d^(8+epsilon)`, Roth's `h(d) >> sqrt(d)` lower bound, and van der Waerden forcing `h(d)->infinity`.

## Bottom line

No improvement to either exponent or a new construction was obtained. The useful conceptual checksum is that #177 is not separate balancing problems for each `d`; it is simultaneous bounded interval discrepancy on every residue-subsequence system, and the systems are not nested in a discrepancy-preserving way.
