# Erdős Problem #153

**Database status at attempt (2026-08-30): OPEN.**

## Problem

Let \(A\) be a finite Sidon set, \(S=A+A=\{s_1<\cdots<s_t\}\), and \(d_i=s_{i+1}-s_i\). Must
\[
\frac1t\sum_{i=1}^{t-1}d_i^2\to\infty
\]
as \(|A|\to\infty\)?

Current database record: https://www.erdosproblems.com/153

## Exact small-gap reduction

For \(h>0\), define
\[
R_S(h)=|\{(u,v)\in S^2:u-v=h\}|.
\]
Every consecutive gap \(d_i=h\) contributes one pair counted by \(R_S(h)\). Hence, for every integer \(H\ge1\),
\[
\#\{i:d_i\le H\}\le\sum_{h=1}^H R_S(h).
\]
Thus proving that the right-hand side is \(o(|A|^2)\) for some \(H=H(|A|)\to\infty\) would immediately solve the problem, since \(t=|A|(|A|+1)/2\): a positive proportion of the gaps would exceed \(H\), forcing the mean square gap to diverge.

The Sidon property turns this into an intersection problem for the difference set of \(A\). Let
\[
r_A(u)=|\{(a,c)\in A^2:a-c=u\}|.
\]
For a Sidon set,
\[
r_A(0)=|A|,\qquad r_A(u)\le1\quad(u\ne0),
\]
because a repeated nonzero difference would give a repeated two-term sum. Every representation of a difference of two elements of \(S\) gives a quadruple of elements of \(A\), so
\[
R_S(h)\le \sum_u r_A(u)r_A(h-u).
\]
Writing \(D^*=\{u\ne0:r_A(u)=1\}\), for \(h>0\) this yields the explicit bound
\[
\boxed{R_S(h)\le 2|A|+|D^*\cap(h-D^*)|.}
\]
Consequently it would suffice to find \(H\to\infty\), \(H=o(|A|)\), for which
\[
\sum_{h=1}^H |D^*\cap(h-D^*)|=o(|A|^2).
\]
This converts the mean-square consecutive-gap problem into a short-shift additive-energy problem for the nonzero difference set of a Sidon set.

## Verification

The only nontrivial input in the boxed inequality is uniqueness of nonzero differences. If \(a-c=a'-c'\ne0\), then \(a+c'=a'+c\); Sidonicity forces the unordered pairs to agree, and the sign of the nonzero difference then forces \((a,c)=(a',c')\).

The reduction does not itself bound the short-shift intersections. In particular, treating \(D^*\) as random would be unjustified: structured Sidon sets can have substantial additive structure in their difference sets.
