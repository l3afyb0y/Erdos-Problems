# Erdős Problem 749

**Current database status checked 2026-08-30:** OPEN.

## Statement
For every `epsilon>0`, does there exist `A subset N` such that the lower density of `A+A` is at least `1-epsilon` while the representation function `r_A(n)=1_A*1_A(n)` is uniformly bounded (with a bound allowed to depend on `epsilon`)?

## Necessary square-root growth window
Assume `r_A(n) <= g` for every `n`, and write

`A(N)=|A intersect [1,N]|`.

Every ordered pair `(a,b)` from `A intersect [1,N]` has sum at most `2N`, so

`A(N)^2 <= sum_{n<=2N} r_A(n) <= 2gN`.

Hence

`A(N) <= sqrt(2gN)`.

Conversely, every element of `(A+A) intersect [1,N]` is represented by a pair from `A intersect [1,N]`, so

`|(A+A) intersect [1,N]| <= A(N)^2`.

If the lower density of `A+A` is at least `1-epsilon`, then for every fixed `eta>0` and all sufficiently large `N`,

`A(N)^2 >= (1-epsilon-eta)N`.

Thus any solution necessarily satisfies

`sqrt((1-epsilon-o(1))N) <= A(N) <= sqrt(2gN)`.

So a successful set must live on the Sidon-scale `Theta(sqrt N)`: it cannot be substantially thinner, and bounded representation prevents it from being substantially thicker.

## Construction obstruction
In particular, eventually periodic positive-density constructions cannot work: periodicity supplies linearly many representations along represented residue classes, contradicting a uniform bound on `r_A(n)`.

These are necessary conditions only; they do not construct a set with lower-density sumset arbitrarily close to one.

## Classification
**Useful reformulation.** The problem is forced into a narrow square-root-density regime, but no construction or contradiction closing the problem was obtained.
