# Erdős Problem #406

**Database status at attempt:** OPEN (2026-08-30)

## Problem

Are there only finitely many powers of 2 whose base-3 expansion uses only the digits 0 and 1?

## Result

**Final label:** useful elementary structure / no progress beyond known frontier.

Any nonzero integer having only ternary digits 0 and 1 is congruent to 1 modulo 3. Hence a candidate exponent \(n\) in \(2^n\) must be even. Write \(n=2m\); then
\[
2^n=4^m=(1+3)^m,
\]
so the problem can be viewed 3-adically as asking for ordinary nonnegative integers \(m\) whose value under the analytic map \(m\mapsto4^m\) lies in the ternary Cantor digit set.

There is also an exact support rule under a two-step exponent shift. If
\[
x=2^n=\sum_j d_j3^j,\qquad d_j\in\{0,1\},
\]
then
\[
2^{n+2}=4x=x+3x=\sum_j(d_j+d_{j-1})3^j.
\]
Because each coefficient is at most 2, no base-3 carries occur in this addition. Consequently \(2^{n+2}\) also has only digits 0 and 1 if and only if the support of the 1-digits of \(2^n\) contains no two consecutive positions. This explains directly why the known examples do not generate an automatic infinite chain: except for the initial 1, their ternary support already contains adjacent 1s.

The branch was pushed into congruence conditions for \((1+3)^m\bmod3^k\), but the resulting 3-adic digit tree did not yield a uniform pruning argument. Finite computation cannot prove the required finiteness.

## Prior-art audit

The maintained page and an August 2026 literature review still classify #406 as open. The strongest cited results remain Narkiewicz's sublinear bound on the number of exceptional exponents and Saye's verification that only exponents 0, 2, and 8 occur through approximately \(5.9\times10^{21}\). The elementary shift/support identity above is not promoted as novel.

No complete proof or disproof was obtained.
