# Erdős Problem 39

**Database status checked 2026-08-30:** OPEN.

**Experiment status:** `no-progress / exact greedy obstruction anatomy`

## Problem

Does there exist an infinite Sidon set `A subset N` with

`|A intersect [1,N]| >>_epsilon N^(1/2-epsilon)`

for every `epsilon>0`?

## Discovery attempt

For a finite Sidon set `S`, adjoining a new integer `x` fails exactly when one of the new sums involving `x` duplicates an old or another new sum. Apart from trivial reorderings, the forbidden values of `x` arise from equations of the forms

`x+a=b+c`, hence `x=b+c-a`,

or

`2x=a+b`.

So the elementary greedy construction is governed by the three-term shadow

`S+S-S`

plus the half-sum obstruction. A crude union bound gives `O(|S|^3)` forbidden locations, which is the familiar cubic-scale barrier behind the elementary `N^(1/3)` construction.

The language-first probe tried to exploit collisions among the forbidden values: many triples may name the same forbidden `x`, so the number of distinct forbidden locations can be much smaller than the number of triples. Rewriting a collision

`b+c-a=b'+c'-a'`

as

`b+c+a' = b'+c'+a`

shows why ordinary Sidonicity does not control this compression: it is a six-variable / three-sum relation rather than a two-sum relation. No sufficiently strong universal collision lower bound was obtained.

## Prior-art audit

The maintained page records the current best infinite construction as Ruzsa's `N^(sqrt(2)-1+o(1))`, far beyond the elementary greedy exponent but still short of `N^(1/2-o(1))`. Thus the decomposition above is only an anatomy of the greedy barrier and is not new progress.
