# Erdős Problem 11

**Database status checked 2026-08-30:** OPEN.

**Experiment status:** `known reduction independently rediscovered / no new progress`

## Problem

Is every sufficiently large odd integer `n` the sum of a squarefree integer and a power of `2`?

Equivalently, must some positive number `n-2^k` be squarefree?

## Exact exponent-cover formulation

Fix odd `n`, and put

`L=floor(log_2(n-1))`.

Suppose `n` is a counterexample. Then each `n-2^k`, `0<=k<=L`, is divisible by a prime square.

For `k>=1`, `n-2^k` is odd, so any such prime is odd. For an odd prime `p`, let

`t_p = ord_{p^2}(2)`.

If

`p^2 | n-2^k`

and

`p^2 | n-2^l`,

then

`2^k == 2^l (mod p^2)`,

hence

`k == l (mod t_p)`.

Therefore, for each odd prime `p`, all exponents killed by the square `p^2` lie in at most one residue class modulo `t_p`.

Thus a counterexample produces a covering of the finite exponent interval `{1,...,L}` by residue classes

`k == r_p (mod t_p)`,

one class for each relevant odd prime square `p^2`. The prime `2` can only affect the exponent `k=0` because `n-2^k` is odd for `k>=1`.

In particular, primes with `t_p>L` can kill at most one exponent in the entire candidate interval. Repeated obstruction across several powers of two is possible only through primes for which the order of `2 mod p^2` is comparatively small.

## Why this did not close the problem

The finite covering statement does not by itself prevent many large-order prime squares from each killing one isolated exponent. A union-density argument over the recurring residue classes therefore does not prove the conjecture: the isolated large-order obstructions are not controlled merely by `sum 1/t_p`.

This is precisely where a tempting short proof fails.

## Prior-art audit

Granville and Soundararajan's 1998 paper is explicitly about this problem and the order of `2 mod p^2`; the maintained problem page describes the strong connection with Wieferich primes. A January 2026 discussion on the problem page also warns that a proposed argument based only on a reciprocal sum of these orders does not yield the full theorem; even assumptions strong enough to make such a sum small were used there only to obtain almost-all results.

Accordingly the exponent-residue formulation is treated as **known structure independently rediscovered**, with no novelty claim.

The current page reports verification for all odd integers below `2^50` but no general proof.
