# Erdős Problem #181

**Database status at attempt:** OPEN (checked 2026-08-30)

**Final classification:** known reduction independently rediscovered / standard bipartite Ramsey lower bound

## Statement

Let `Q_n` be the `n`-dimensional hypercube. Prove `R(Q_n) << 2^n`.

Current status source: https://www.erdosproblems.com/181

## Discovery pass

The target says that a red/blue complete graph on only a constant multiple of the cube's `2^n` vertices must already contain a monochromatic cube. Since `Q_n` is connected and bipartite with two equal parts of size `2^(n-1)`, the first structural question is how far the elementary bipartition obstruction can delay Ramsey forcing.

Colour a complete graph on

`(2^n-1) + (2^(n-1)-1) = 3*2^(n-1)-2`

vertices by splitting the vertices into parts `X,Y`, colouring edges inside each part red and all cross-edges blue.

A red `Q_n` cannot occur because every red component has fewer than `2^n` vertices. A blue `Q_n` cannot occur because the blue graph is `K_{|X|,|Y|}` and a connected bipartite copy of `Q_n` must place its two unique bipartition classes, each of size `2^(n-1)`, on opposite sides; but `|Y|=2^(n-1)-1`.

Therefore

`R(Q_n) >= 3*2^(n-1)-1`.

The argument is exact but does not address the upper bound.

## Prior-art audit

This is the standard Burr-type lower-bound construction for bipartite Ramsey problems, not new. Work on cube-versus-clique Ramsey numbers explicitly records the general lower bound `(s-1)(2^n-1)+1`; the present diagonal construction is the same obstruction specialised to a two-block red/blue colouring.

The current best upper bound recorded by the Erdős database remains Tikhomirov's `R(Q_n) << 2^((2-c)n)` for a small positive `c`, far above the conjectured linear-in-`2^n` scale.

## Bottom line

The elementary lower obstruction was independently rediscovered and checked, but no new upper-bound mechanism was found. The problem remains open.
