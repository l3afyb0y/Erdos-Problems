# Erdős Problem 85

**Database status checked 2026-08-30:** OPEN.

**Experiment status:** `useful reformulation / no new asymptotic progress`

## Problem

Let `f(n)` be the least integer such that every `n`-vertex graph with minimum degree at least `f(n)` contains a `C4`. Is `f(n+1)>=f(n)` for all sufficiently large `n`?

Equivalently, if

`g(n)=max{delta(G): |V(G)|=n and G is C4-free}`,

is `g(n+1)>=g(n)` eventually?

## Exact one-vertex extension criterion

Let `G` be `C4`-free and add a new vertex `x` whose neighborhood is a set `S subset V(G)`.

Then the enlarged graph is `C4`-free **if and only if** no two distinct vertices of `S` have a common neighbor in `G`.

Indeed, if `u,v in S` share a neighbor `w`, then

`x-u-w-v-x`

is a `C4`. Conversely, every new `C4` must contain `x`; deleting `x` from it exhibits two vertices of `S` with a common neighbor in `G`.

Define the auxiliary common-neighbor graph `H_G` on `V(G)` by

`uv in E(H_G)` iff `u` and `v` have a common neighbor in `G`.

Then a set `S` is a legal neighborhood for a new vertex exactly when it is an independent set of `H_G`.

Consequently, if some extremal `C4`-free `n`-vertex graph `G` with minimum degree `d=g(n)` satisfies

`alpha(H_G)>=d`,

then one may add a vertex adjacent to any independent `d`-set of `H_G`; the enlarged graph is `C4`-free and still has minimum degree at least `d`. Therefore

`g(n+1)>=g(n)`.

Thus any failure of the desired monotonicity at `n` forces **every** extremal witness `G` to satisfy

`alpha(H_G)<g(n)`.

## Exact local degree identity

Because `G` is `C4`-free, two different neighbors of a vertex `u` cannot lead to the same second neighbor other than `u`. Hence

`deg_{H_G}(u) = sum_{w in N_G(u)} (deg_G(w)-1)`.

This makes the obstruction explicit. In the near-extremal regime `g(n)~sqrt(n)`, the auxiliary graph can have degrees on the order of `n`, so elementary independence-number estimates do not force an independent set of size `g(n)`.

## Why this did not close the problem

The criterion converts the desired monotone extension into a concrete independent-set problem, but the common-neighbor graph can be extremely dense. No structural argument was found showing that an extremal `C4`-free graph must have `alpha(H_G)>=delta(G)` for all large orders, nor was a counterexample mechanism produced.

The maintained Erdős Problems page and the July 2026 TheoremDB snapshot both list the full monotonicity statement as OPEN. The extension criterion is elementary and no novelty claim is made.
