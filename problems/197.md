# Erdős Problem #197

**Database status at attempt:** OPEN  
**Status checked:** 2026-08-30  
**Experiment result:** known/basic reduction independently rediscovered / infinite order-type barrier

## Problem

Can \(\mathbb N\) be partitioned into two sets, each of which can be permuted to avoid monotone 3-term arithmetic progressions?

Maintained source: https://www.erdosproblems.com/197

## Discovery record

A finite obstruction cannot work here for a very strong elementary reason.

### Lemma

Every finite set of integers admits a permutation containing no monotone 3-term arithmetic progression.

### Proof

Proceed recursively by parity. List the elements of one parity first and the elements of the other parity second; within each parity class, divide the translated values by two and apply the same rule recursively. The recursion terminates on a finite set.

Consider any 3-term arithmetic progression \(x,x+d,x+2d\) contained in the set.

- If \(d\) is odd, the endpoints have the same parity and the midpoint has the opposite parity. Hence the midpoint lies in the other parity block from both endpoints, so its position cannot lie between their positions. The progression is not monotone.
- If \(d\) is even, all three terms have the same parity. After dividing that parity class by two, they remain a 3-term arithmetic progression, and the recursive avoidance applies.

Thus the resulting finite permutation avoids every monotone 3-AP.

### Consequence for #197

The unresolved content is therefore purely infinite. A naive infinite version of the same recursion fails because an \(\omega\)-permutation cannot list an infinite parity block completely and then proceed to another infinite block.

More generally, if one insists on a recursively block-separated 2-adic ordering of an infinite set \(A\), then for the order to have type \(\omega\), at each recursive residue node the earlier child must be finite. This forces \(A\) to become asymptotically concentrated along one 2-adic residue path. Two such concentrated sets cannot obviously partition all of \(\mathbb N\); infinitely many residue classes remain to be covered. This shows why the finite parity construction does not directly lift to the requested two-set partition.

The attempt did not find an interleaving rule that preserves the non-betweenness condition while giving both colour classes honest \(\omega\)-enumerations.

## Prior-art / status audit

The maintained database lists #197 as OPEN and notes that three sets suffice. The finite parity-recursive avoidance phenomenon belongs to the classical finite permutation literature (Davis--Entringer--Graham--Simmons and later work), so it is recorded here as a rediscovered basic structural fact rather than a novelty claim.
