# Erdős Problem #128

**Database status at attempt (2026-08-30): OPEN / falsifiable.**

## Problem

If every induced subgraph of an \(n\)-vertex graph \(G\) on at least \(\lfloor n/2\rfloor\) vertices has more than \(n^2/50\) edges, must \(G\) contain a triangle?

Current database record: https://www.erdosproblems.com/128

## Exact neighbourhood-anchored half-set inequality

Assume for contradiction that \(G\) is triangle-free, and put \(h=\lfloor n/2\rfloor\). For every vertex \(v\), its neighbourhood \(N(v)\) is independent. Therefore \(d(v)<h\), since otherwise \(N(v)\) itself would contain an independent \(h\)-vertex set, contradicting the hypothesis.

Fix \(v\), write \(d=d(v)\),
\[
R=V(G)\setminus(N(v)\cup\{v\}),\qquad r=|R|=n-d-1,
\]
and let \(t=h-d\). Choose \(T\subset R\) uniformly among all \(t\)-subsets and set
\[
H=N(v)\cup T.
\]
Then \(|H|=h\), and since \(N(v)\) is independent,
\[
\mathbb E e(G[H])
=\frac{t}{r}e(N(v),R)
+\frac{t(t-1)}{r(r-1)}e(R).
\]
Consequently the Erdős--Rousseau hypothesis forces, for every vertex \(v\),
\[
\boxed{
\frac{h-d(v)}{n-d(v)-1}\,e(N(v),R_v)
+\frac{(h-d(v))(h-d(v)-1)}{(n-d(v)-1)(n-d(v)-2)}\,e(R_v)
>\frac{n^2}{50}.}
\]
This is an exact necessary local inequality for any triangle-free counterexample.

The first term can also be written
\[
e(N(v),R_v)=\sum_{u\in N(v)}(d(u)-1),
\]
because triangle-freeness forbids edges inside \(N(v)\). Hence every hypothetical counterexample must satisfy a coupled system involving each degree and the sum of the neighbouring degrees, rather than only the global edge count.

## Why the branch did not close

For a roughly \(cn\)-regular triangle-free graph, the displayed expectation has main-term density
\[
\frac{c(1-2c)}{8(1-c)^2},
\]
whose maximum is \(1/32\) at \(c=1/3\). Thus this elementary neighbourhood-anchored averaging mechanism naturally stalls above the target \(1/50\). It does not by itself reach the conjectured sparse-half constant.

The maintained database records substantially stronger published bounds (including Razborov's \(27/1024\) replacement for \(1/50\)), so the exact inequality above is best treated as structural bookkeeping rather than a frontier improvement.
