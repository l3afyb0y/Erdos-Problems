# Erdős Problem 52

**Database status checked 2026-08-30:** OPEN.

## Problem

For every `epsilon>0`, is there a constant `c_epsilon>0` such that every finite set `A` of integers satisfies

\[
\max\{|A+A|,|AA|\}\ge c_\epsilon |A|^{2-\epsilon}?
\]

## Exact pair encoding

For an unordered pair `{a,b}`, the pair of values

\[
(a+b,ab)
\]

determines `{a,b}`, since `a` and `b` are the two roots of

\[
x^2-(a+b)x+ab=0.
\]

Therefore the map from unordered pairs with repetition to `(sum,product)` pairs is injective. If `N=|A|`, then

\[
\binom{N+1}{2}\le |A+A|\,|AA|.
\]

Consequently

\[
\max\{|A+A|,|AA|\}\ge\sqrt{\binom{N+1}{2}}.
\]

This only gives a linear-scale lower bound and is far weaker than the best known sum-product exponents.

## Where the elementary route stalls

To improve the bound one must show that the set of attainable `(sum,product)` pairs occupies substantially more than the bare injectivity count forces when one projection is small. Equivalently, one needs strong control of additive and multiplicative collision energies simultaneously. Passing to prime-valuation vectors linearizes multiplication but leaves ordinary addition highly nonlinear, so no elementary invariant found in this attempt couples the two structures strongly enough to improve the known frontier.

## Prior-art audit

The maintained Erdős Problems database still lists #52 as OPEN. Current work already proves exponents substantially larger than the elementary bound above; no claim in this attempt improves those results.
