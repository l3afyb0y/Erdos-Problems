# Erdős Problem #341

**Database status at attempt:** OPEN (checked 2026-08-30)

## Problem

Starting from a finite set of positive integers, repeatedly adjoin the least larger integer which is not a sum of two earlier selected integers. Are the successive differences eventually periodic?

## Result

**Final classification:** known/basic structural reduction; no new global progress.

Past the largest initial seed value, the greedy rule has an exact static form. If `A` denotes the final infinite set, then for every sufficiently large integer `n`,

`n in A  <=>  n notin A+A`.

Indeed, if `n=a+b` in the final set then `a,b<n`, hence both summands were already available when `n` was considered; conversely the greedy rule selects `n` exactly when no such earlier representation exists.

Thus the tail is simultaneously sum-free and asymptotically complete: every sufficiently large integer outside `A` lies in `A+A`. Eventual periodicity asks whether every greedy tail generated from a finite seed eventually enters a periodic fixed point of this complement/sumset relation.

This did not yield an argument forcing periodicity. In particular, the relation itself is too weak: complete sum-free structure does not provide an obvious finite-memory rule.
