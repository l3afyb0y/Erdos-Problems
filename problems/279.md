# Erdős Problem 279

**Database status checked 2026-08-30:** OPEN.

**Experiment classification:** useful reformulation / no complete progress.

## Problem

For fixed `k>=3`, can one choose one residue class `a_p (mod p)` for every prime `p` so that every sufficiently large integer is of the form

`a_p + t p`

for some prime `p` and integer `t>=k`?

## Moving-sieve formulation

For a fixed integer `n`, a representation requires a prime `p<=n/k` with `n == a_p (mod p)`. Conversely, if there is a prime

`p <= n/(k+1)`

with `n == a_p (mod p)`, then, taking the representative `0<=a_p<p`,

`n-a_p >= n-(p-1) > kp`,

so the corresponding quotient `t=(n-a_p)/p` is at least `k`.

Thus the original problem is sandwiched between two moving sieve-cover statements:

- **necessary:** every sufficiently large `n` is hit by one of the chosen classes for a prime `p<=n/k`;
- **sufficient:** every sufficiently large `n` is hit by one of the chosen classes for a prime `p<=n/(k+1)`.

The threshold condition `t>=k` therefore costs only the narrow multiplicative window between `n/(k+1)` and `n/k`; the main difficulty is already a dynamic covering problem for one chosen residue modulo each prime.

## Capacity check

After choosing residues for primes up to `y`, a generic sieve leaves on the order of `y/log y` survivors in an interval of length comparable to `y`, while there are also on the order of `y/log y` primes available up to `y`. This explains why a greedy strategy is at a critical constant-density scale rather than being obviously over- or under-supplied. No deterministic invariant was found that drives the survivor count below the available new-prime capacity at every scale.

This reformulation does not solve the problem. The maintained Erdős Problems page still lists #279 as OPEN, and the pre-attempt claim audit found no credible complete proof or disproof.
