# Erdős Problem 312

**Current database status checked 2026-08-30:** OPEN.

## Statement
Does there exist an absolute `c>0` such that every sufficiently large finite multiset `A` of positive integers with reciprocal mass

`R(A)=sum_{n in A} 1/n > K > 1`

has a submultiset `S` satisfying

`1-exp(-cK) < R(S) <= 1`?

## Elementary cutoff lemma
Define

`epsilon(A)=1-max{R(S): S subset A, R(S)<=1}`.

Assume `epsilon(A)>0`, and choose a maximizing submultiset `S`.

If an omitted item has denominator `q` with `1/q <= epsilon(A)`, then adding it to `S` still gives reciprocal sum at most `1`, contradicting maximality. Hence every omitted reciprocal is strictly larger than `epsilon(A)`. Equivalently, every item with denominator `q >= 1/epsilon(A)` is forced into `S`.

Also, if denominator `q` occurs at least `q` times in `A`, then `q` copies have reciprocal sum exactly `1`, contradicting `epsilon(A)>0`. Thus its multiplicity is at most `q-1`.

Consequently, writing `delta=epsilon(A)`,

`R(A) <= 1 + sum_{q < 1/delta} (q-1)/q < 1 + 1/delta`.

Therefore

`epsilon(A) < 1/(R(A)-1)`.

This is only a baseline estimate. Erdős and Graham already obtained the stronger order `O(1/K^2)`, so this does not improve the known bound.

## Classification
**No progress** toward the exponential conjecture. The cutoff lemma is a clean sanity check exposing what a maximal under-approximation forces, but it is weaker than the classical result.
