# Erdős Problem #80

**Database status at attempt:** OPEN (2026-08-30)

## Problem

For fixed \(c>0\), let \(f_c(n)\) be the largest \(m\) such that every \(n\)-vertex graph with at least \(cn^2\) edges, every edge lying in a triangle, contains a book of size at least \(m\). Estimate \(f_c(n)\); in particular, does \(f_c(n)\gg\log n\)?

## Result

**Final label:** no progress / elementary incidence anatomy.

Let \(B\) be the maximum book size, \(e=|E(G)|\), and \(t\) the number of triangles. For every vertex \(v\), the number of edges in the induced neighborhood \(G[N(v)]\) equals the number of triangles containing \(v\), hence
\[
\sum_v e(G[N(v)])=3t.
\]
Since every edge lies in at least one triangle, \(3t\ge e\). Moreover, for every \(x\in N(v)\),
\[
d_{G[N(v)]}(x)=|N(v)\cap N(x)|\le B,
\]
so
\[
e(G[N(v)])\le \frac{B\,d(v)}2.
\]
These identities re-express the problem as a dense edge set covered by induced-neighborhood edge sets with bounded local multiplicity. The immediate inequalities yield only constant lower bounds for \(B\), not the desired logarithmic growth.

The attempt then tried to iterate the neighborhood structure, but an edge of \(G[N(v)]\) need not have its supporting triangle inside \(N(v)\); the witness can leave the neighborhood. This breaks the naive recursion. No stronger invariant was obtained.
