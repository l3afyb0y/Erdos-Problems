# Erdős Problem #28

**Database status at attempt:** OPEN

**Experiment status:** known reduction independently rediscovered

## Statement

If `A subset N` has cofinite sumset `A+A`, must the ordered representation function `r_A(n)` be unbounded?

## Low-bound obstruction

Assume for contradiction that eventually `r_A(n) <= 2`. Since off-diagonal ordered representations occur in symmetric pairs, `r_A(n)` is even for odd `n`. Cofiniteness of `A+A` therefore forces `r_A(n)=2` for all sufficiently large odd `n`. For even `n=2m`, parity gives `r_A(2m) == 1_A(m) (mod 2)`, so eventual positivity and the bound `<=2` force

`r_A(2m)=1` if `m in A`, and `r_A(2m)=2` otherwise.

Let `F(z)=sum_{a in A} z^a`. Up to a polynomial error from finitely many initial coefficients,

`F(z)^2 = 2/(1-z) - F(z^2) + P(z)`.

Put `z=-r` with `0<r<1`. Then

`F(-r)^2 = 2/(1+r) - F(r^2) + P(-r)`.

As `r -> 1^-`, the right side tends to `-infinity` because `F(r^2)->infinity`, while the left side is nonnegative. Contradiction. Hence an asymptotic basis cannot have ordered representation function eventually bounded by `2`.

## Prior-art audit

This is not new progress toward the full conjecture. The classical Dirac line already excludes perfect/uniquely represented asymptotic bases, and later work on quantitative forms of the Erdős-Turán conjecture gives stronger finite lower bounds. The present argument is a compact rediscovery in ordered-representation language.

Current status remains OPEN; unboundedness is still unknown.
