# Erdős Problem #203

**Database status at attempt:** OPEN  
**Status checked:** 2026-08-30  
**Experiment result:** known reduction independently rediscovered / bounded CRT-cover search did not close

## Problem

Is there an integer \(m\ge1\), with \((m,6)=1\), such that

\[
2^k3^\ell m+1
\]

is composite for every \(k,\ell\ge0\)?

Maintained source: https://www.erdosproblems.com/203

## Discovery record

The natural finite-certificate route is a covering problem on the exponent lattice.

Let \(q>3\) be prime. Choose a primitive root \(g\pmod q\), and write

\[
2=g^{e_2},\qquad 3=g^{e_3}.
\]

Set

\[
d=\gcd(q-1,e_2,e_3),\qquad h=(q-1)/d,
\]

and

\[
a=e_2/d,\qquad b=e_3/d.
\]

Then the subgroup \(\langle2,3\rangle\le\mathbb F_q^*\) has order \(h\). Choosing one nonzero residue class for \(m\pmod q\) is equivalent to choosing one phase \(t\pmod h\), and \(q\) divides the target term exactly on one affine modular fibre

\[
\boxed{ak+b\ell\equiv t\pmod h.}
\]

Therefore a finite set of certificate primes gives a complete positive solution if their chosen fibres cover every \((k,\ell)\in\mathbb Z_{\ge0}^2\). The Chinese remainder theorem then combines the corresponding congruences for \(m\); adding \(m\equiv1\pmod6\) preserves \((m,6)=1\), and choosing the positive CRT representative larger than every certificate prime ensures divisibility is nontrivial, so every target value is composite rather than equal to its certificate prime.

A necessary density condition for any such finite prime-fibre cover is

\[
\sum_q \frac1{h_q}\ge1.
\]

### Bounded period-5040 search

I enumerated primes for which the subgroup order \(h_q\) divides \(5040\). The genuine list has 31 primes, and

\[
\sum \frac1{h_q}=1.021428571\ldots=\frac{143}{140}.
\]

So the crude density obstruction is just barely passed.

I then represented each prime by its exact linear form \(a_qk+b_q\ell\pmod{h_q}\) and performed repeated coordinate-descent phase searches on 300,000 uniformly sampled residue pairs modulo 5040. Across 20 random starts the best assignment still left about 27.8% of sampled pairs uncovered. This is heuristic negative evidence only: it is neither an infeasibility certificate nor a lower bound for the exact covering problem.

The strongest branch therefore did not reach a CRT witness.

## Prior-art audit

Post-discovery searching found an August 3, 2026 public #203 report giving exactly the same affine-fibre formulation, including

\[
ak+b\ell\equiv t\pmod h
\]

and the CRT completion step. It also reports much deeper bounded searches and no full cover. A later recency audit corrected false "prime" entries in an earlier extension and confirms that the period-5040 genuine-prime list contains exactly the same 31 primes used here.
