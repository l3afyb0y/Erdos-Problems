# Erdős Problem #212

**Database status at attempt:** OPEN  
**Attempt date:** 2026-08-30  
**Final classification:** candidate/new partial lemma — novelty unresolved

## Problem

Is there a dense subset of \(\mathbb R^2\) such that every pairwise distance is rational?

This is the Erdős–Ulam rational-distance problem. The maintained Erdős Problems database still listed it `open` at selection time. A narrow pre-discovery audit found only the known conditional negative results (Bombieri–Lang/Lang-type hypotheses), not an unconditional solution.

## Unresolved quantifier

The full target asks for one of two genuinely global conclusions:

- construct a subset dense in the whole plane for which **every** pair has rational distance; or
- prove unconditionally that **no** such dense set can exist.

Finite configurations, fixed-denominator bounds, or restrictions on special line sections do not discharge that quantifier.

## Discovery reduction: rational affine coordinates

Let \(S\) be a noncollinear rational-distance set and choose noncollinear \(A,B,C\in S\). Put

\[
e=B-A,\qquad f=C-A.
\]

Because all three side lengths of \(ABC\) are rational,

\[
 e\cdot e,\quad f\cdot f,\quad e\cdot f
\]

are rational. For any \(P\in S\), put \(w=P-A\). Then

\[
 w\cdot e=\frac{|w|^2+|e|^2-|P-B|^2}{2}\in\mathbb Q,
\]

and similarly \(w\cdot f\in\mathbb Q\). The Gram matrix of \(e,f\) is invertible with rational entries, so the coefficients in

\[
P=A+x e+y f
\]

are rational:

\[
\boxed{x,y\in\mathbb Q.}
\]

Thus every noncollinear rational-distance set is contained in one rational affine plane

\[
A+\mathbb Q e+\mathbb Q f.
\]

This alone is not an obstruction to Euclidean density.

## Candidate partial lemma: denominator-mesh sparsity

Fix \(R>0\). For a positive integer \(D\), let

\[
S_D(R)=\left\{P\in S:
P=A+\frac mD e+\frac nD f,
\ |m|,|n|\le RD
\right\}.
\]

Then

\[
\boxed{|S_D(R)|\le D^{1+o(1)}}
\qquad(D\to\infty),
\]

where the implicit constants depend on the fixed triangle \(A,B,C\) and on \(R\).

Equivalently, among the \(\asymp D^2\) sites of any bounded common-denominator \(D\)-mesh in these rational affine coordinates, a noncollinear rational-distance set occupies only a subpolynomial multiple of \(D\) sites.

### Proof

Let

\[
d=|e|\in\mathbb Q_{>0},\qquad
\lambda=\frac{e\cdot f}{d^2}\in\mathbb Q,
\]

and let

\[
h^2=|f|^2-\frac{(e\cdot f)^2}{d^2}\in\mathbb Q_{>0}.
\]

Then for rational coordinates \((x,y)\),

\[
|x e+y f|^2=d^2(x+\lambda y)^2+h^2y^2.
\]

Fix a nonzero row index \(n\). If

\[
P=A+\frac mD e+\frac nD f\in S,
\]

then \(|P-A|\in\mathbb Q\). Hence

\[
(D|P-A|)^2=d^2(m+\lambda n)^2+h^2n^2.
\]

Choose once and for all a positive integer \(L\) such that

\[
Ld\in\mathbb Z,\qquad Ld\lambda\in\mathbb Z,
\qquad K:=L^2h^2\in\mathbb Z_{>0}.
\]

Then

\[
(LD|P-A|)^2=U^2+Kn^2,
\]

where

\[
U=Ld(m+\lambda n)\in\mathbb Z.
\]

The right side is an integer. Since \(LD|P-A|\) is rational and its square is an integer, it is itself an integer; call it \(M\). Therefore

\[
(M-U)(M+U)=Kn^2.
\]

Every admissible \(m\) yields an integer factor pair of the fixed integer \(Kn^2\), and \(U\) determines \(m\) uniquely. Consequently

\[
\#\{m:P\in S\text{ on row }n\}
\le 2\tau(Kn^2),
\]

with the harmless factor \(2\) absorbing signs.

For the row \(n=0\), distance from \(A\) gives no restriction because that row contains the baseline \(AB\). Use the off-row anchor \(C\) instead. Relative to \(C\), the row has vertical coordinate \(-1=-D/D\), and the identical factorisation gives

\[
\#\{m:P\in S\text{ on row }0\}
\le 2\tau(KD^2).
\]

There are \(O_R(D)\) rows with \(|n|\le RD\). For every such nonzero \(n\), the integer \(Kn^2\) is \(O_{K,R}(D^2)\). The classical divisor bound

\[
\tau(N)=\exp\!\left(O\!\left(\frac{\log N}{\log\log N}\right)\right)=N^{o(1)}
\]

therefore gives, uniformly over the rows,

\[
\tau(Kn^2)=D^{o(1)},
\]

and the same holds for \(\tau(KD^2)\). Summing the row bounds proves

\[
|S_D(R)|=D^{1+o(1)}.
\]

## Strong one-dimensional corollary

Fix a line through two points of a noncollinear rational-distance set and normalize those two points to affine coordinates \(0,1\) on the line. For every fixed \(D\), only finitely many points of the set can have line-coordinate in \(D^{-1}\mathbb Z\).

More quantitatively, after fixing one point of the set off that line, the number of such points in a bounded interval is controlled by a divisor function of a quadratic-size integer.

Thus an infinite equally spaced collinear progression inside a rational-distance set forces the entire set to be collinear.

## Why the argument does not solve #212

The preserved state is the denominator scale. The factorisation strongly limits occupation of each **fixed common denominator mesh**, but topological density does not require a dense set to occupy many points of any one mesh. A hypothetical dense set may escape every finite denominator scale by using rapidly increasing and mutually incompatible denominators.

The tempting converse fails:

> Euclidean density does **not** imply positive density, or even many points, in any fixed rational lattice mesh.

No operation discovered in this run converts nearby dense points to mesh points while preserving all rational-distance constraints. Therefore the mesh lemma does not iterate into a contradiction with density.

## Adversarial checks

- Noncollinearity of \(A,B,C\) is essential so the Gram matrix is invertible and \(h^2>0\).
- The coefficient of the horizontal square is a rational square because \(|AB|=d\in\mathbb Q\); this is what makes the difference-of-squares factorisation integral after one fixed clearing denominator.
- The \(n=0\) row is a genuine boundary case. Using distance to \(A\) there gives no bound; using the off-row anchor \(C\) repairs it.
- The argument counts only common-denominator mesh points. It does not bound all rational points of bounded Euclidean size without a denominator restriction.
- No finite computation is used to discharge an infinite quantifier.

An exact finite sanity checker for the factorisation on the \(3\)-\(4\)-\(5\) reference triangle is stored at [`verification/212_denominator_mesh.py`](../verification/212_denominator_mesh.py). It checks all rows for \(D\le40\) and \(|m|,|n|\le8D\). This is verification only, not discovery.

## Prior-art audit

The maintained Erdős Problems page still lists #212 as open. Known negative results remain conditional on major arithmetic-geometric conjectures; unconditional work controls rational-distance sets on algebraic curves or in general position under additional hypotheses.

Post-discovery searches targeted:

- rational-distance sets plus denominator bounds;
- arithmetic progressions on a line inside rational-distance sets;
- divisor-function bounds for rational-distance configurations;
- common-denominator lattice/mesh formulations;
- recent rational-distance papers and recent AI-assisted working sources.

The search located literature on rational points at prescribed rational distances, elliptic-curve constructions, and the standard conditional Erdős–Ulam program, but did not locate this exact \(D^{1+o(1)}\) common-denominator mesh bound or the row-wise divisor-factorisation statement.

Search failure is not proof of novelty. The correct status is therefore

**candidate/new partial lemma — novelty unresolved**.

The full Erdős–Ulam problem remains open.
