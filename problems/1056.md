# Erdős Problem 1056

**Current database status checked 2026-08-30:** OPEN.

## Statement
For every integer `k >= 2`, does there exist a prime `p` and `k` consecutive intervals of integers whose products are all congruent to `1 (mod p)`?

## Exact factorial-residue reduction
Let `p` be prime and let

`0 <= q_0 < q_1 < ... < q_k < p`.

For `1 <= i <= k`, put

`I_i = {q_{i-1}+1, ..., q_i}`.

Then

`prod_{n in I_i} n = q_i! / q_{i-1}! (mod p)`,

because every factorial up to `p-1` is invertible modulo `p`. Hence

`prod_{n in I_i} n == 1 (mod p)`

if and only if

`q_i! == q_{i-1}! (mod p)`.

Therefore `k` consecutive intervals of the required kind are equivalent to finding one residue class modulo `p` hit by at least `k+1` factorials among `0!,1!,..., (p-1)!` (or the corresponding shifted convention if the initial endpoint is required positive).

This is the natural factorial formulation also reflected by the Noll--Simmons variant and OEIS A060427. Thus this reduction is **known structure independently rediscovered**, not a novel solution.

## Exact verification examples
A direct modular scan reproduced the following factorial collisions:

- `p=23`: `1!,4!,8!,11!,21! == 1 (mod 23)`, giving 4 consecutive product-one intervals.
- `p=71`: `7!,9!,19!,51!,61!,63!,70! == -1 (mod 71)`, giving 6 intervals.
- `p=599`: factorial indices `28,50,122,183,250,289,500,539,555` all have residue `175`, giving 8 intervals.
- `p=3011`: factorial indices `1,611,723,749,805,2205,2261,2287,2399,3009` all have residue `1`, giving 9 intervals.

These agree with the classical OEIS sequence A060427; they are verification data, not new records.

## Classification
**Known reduction independently rediscovered.** The open problem becomes the unbounded-multiplicity question for factorial residues modulo primes. No proof of unbounded multiplicity was obtained.
