# Erdős Problem 41

**Database status checked 2026-08-30:** OPEN.

**Experiment status:** `useful reformulation / exact translate-intersection structure`

## Problem

Let `A subset N` be an infinite `B_3` set: every three-term sum is unique up to permutation. Must

`liminf A(N)/N^(1/3) = 0`?

## Exact translate-intersection lemma

Let `S` be any finite `B_3` set and, for each `a in S`, define

`X_a = a + (S+S)`,

where `S+S` is the set of unordered two-term sums, repetitions allowed.

For distinct `a,a' in S`,

`X_a intersect X_a' = {a+a'+s : s in S}`.

Proof: if

`a+b+c = a'+d+e`,

then `B_3` uniqueness forces the multisets `{a,b,c}` and `{a',d,e}` to be equal. Since `a != a'`, the left multiset must contain `a'` among `b,c`, the right must contain `a` among `d,e`, and the remaining entries agree. Conversely every `a+a'+s` belongs to both translates.

For three distinct anchors `a,a',a''`,

`X_a intersect X_a' intersect X_a'' = {a+a'+a''}`,

and no point belongs to four distinct anchored translates.

This completely describes the overlap pattern among the anchored two-sum translates.

## What the lemma does and does not do

Inclusion-exclusion with these exact intersections merely reconstructs the tautological count of three-term multisets, `binom(|S|+2,3)`. Thus the clean overlap geometry alone does not force the required liminf drop. The unresolved leverage would have to come from combining this rigid intersection pattern with *where* the translates sit on the integer line across multiple scales.

## Prior-art audit

The maintained page records the odd `h=3` liminf problem as open; analogous results are known for `h=2`, `h=4`, and all even `h`. A narrow search did not locate this exact anchored-translate lemma as a named result, but it is an immediate consequence of the definition and is not claimed as substantial novelty.
