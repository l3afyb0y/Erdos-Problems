# Erdős Problem 971

**Current database status checked 2026-08-30:** OPEN.

## Statement
Let `p(a,d)` be the least prime congruent to `a (mod d)`. Does there exist `c>0` such that for every sufficiently large `d`, a positive proportion of the reduced residue classes `a (mod d)` satisfy

`p(a,d) > (1+c) phi(d) log d`?

## Occupancy / collision reformulation
Fix `d` and a cutoff `X`. For each reduced residue class `a (mod d)`, let

`r_a(X) = #{ primes p <= X : p == a (mod d) }`.

Write

`P = sum_a r_a`,

`Q = sum_a r_a(r_a-1)`,

and let `L` be the number of reduced residue classes containing no prime at most `X`.

The number of occupied classes is `O = phi(d)-L`. By Cauchy--Schwarz,

`P^2 <= O * sum_a r_a^2 = O * (P+Q)`.

Therefore

`O >= P^2/(P+Q)` is the usual direction, while applying Cauchy to the occupied classes only gives exactly this lower bound on occupancy. For a lower bound on empty classes one instead uses the elementary collision identity

`P-O = sum_{r_a>0}(r_a-1)`

and the inequality `r-1 <= r(r-1)/2`, yielding

`L = phi(d)-O >= phi(d)-P` (trivial) and

`L = phi(d)-P + (P-O)`.

Thus, once `P` exceeds `phi(d)`, the problem is precisely to force enough *collisions* among the early primes: repeated primes in the same residue class compensate for the excess `P-phi(d)` and leave classes empty.

Equivalently, the relevant collision count is

`C = sum_a binom(r_a,2)`,

which counts pairs of distinct primes `p,q <= X` with `p == q (mod d)`, i.e. with `p-q` a nonzero multiple of `d`.

This makes the hard input explicit: at the natural cutoff

`X=(1+c)phi(d)log d`,

one needs enough same-class prime collisions uniformly in large `d`. That is a prime-correlation problem at shifts `md`.

## Exact numerical check
For `c=0.1`, direct prime enumeration gives substantial empty-class counts for typical composite moduli. Examples `(d, phi(d), X, P, L)`:

- `(120, 32, 168, 36, 5)`
- `(300, 80, 501, 92, 14)`
- `(840, 192, 1422, 219, 32)`
- `(1000, 400, 3039, 433, 76)`
- `(3000, 800, 7045, 903, 169)`

These are finite checks only.

## Classification
**Useful reformulation.** The language-level "first prime arrival in each residue box" picture compiles to an exact occupancy/collision formulation. No uniform lower bound on the required prime-pair collisions was proved, so the Erdős problem remains open.
