# Erdős Problem 971

**Current database status checked 2026-08-30:** OPEN.

## Statement
Let `p(a,d)` be the least prime congruent to `a (mod d)`. Does there exist `c>0` such that for every sufficiently large `d`, a positive proportion of the reduced residue classes `a (mod d)` satisfy

`p(a,d) > (1+c) phi(d) log d`?

## Occupancy / collision reformulation
Fix `d` and a cutoff `X`. For each reduced residue class `a (mod d)`, let

`r_a(X) = #{ primes p <= X : p == a (mod d) }`.

Write

`P = sum_a r_a`,

`Q = sum_a r_a(r_a-1)`,

and let `L` be the number of reduced residue classes containing no prime at most `X`.

The number of occupied classes is `O = phi(d)-L`. By Cauchy--Schwarz,

`P^2 <= O * sum_a r_a^2 = O * (P+Q)`.

Therefore

`O >= P^2/(P+Q)`.

For empty classes the exact first-order identity is more revealing:

`P-O = sum_{r_a>0}(r_a-1)`

and hence

`L = phi(d)-O = phi(d)-P + (P-O)`.

Thus, once `P` exceeds `phi(d)`, empty residue classes exist only to the extent that repeated arrivals of early primes create enough **redundancy** `P-O` to compensate for the excess `P-phi(d)`.

The pair-collision statistic

`C = sum_a binom(r_a,2)`

counts pairs of distinct primes `p,q <= X` with `p == q (mod d)`, equivalently with `p-q` a nonzero multiple of `d`. It satisfies

`P-O = sum_{r_a>0}(r_a-1) <= C`.

However, `C` is not literally equivalent to `P-O`: a large number of prime pairs can be concentrated in a few heavily occupied residue classes. Therefore a lower bound on pair correlations alone does not automatically give the required lower bound on empty classes without additional information controlling how those collisions are distributed.

At the natural cutoff

`X=(1+c)phi(d)log d`,

the hard input is a uniform lower bound on the first-order redundancy `P-O` (or a prime-correlation estimate strong enough, together with concentration control, to imply one). This is where the prime-correlation difficulty at shifts `md` enters.

## Exact numerical check
For `c=0.1`, direct prime enumeration gives substantial empty-class counts for typical composite moduli. Examples `(d, phi(d), X, P, L)`:

- `(120, 32, 168, 36, 5)`
- `(300, 80, 501, 92, 14)`
- `(840, 192, 1422, 219, 32)`
- `(1000, 400, 3039, 433, 76)`
- `(3000, 800, 7045, 903, 169)`

A fresh reproduction audit independently recomputed all five tuples exactly and obtained the same values. These are finite checks only.

## Classification
**Useful reformulation.** The exact occupancy identity reproduces. The original wording overstated the role of the pair-collision count by calling it equivalent to the needed redundancy; that has been corrected. No uniform lower bound on the required redundancy was proved, so the Erdős problem remains open.
