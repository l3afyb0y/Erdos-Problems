# Erdős Problem #25

**Database status at attempt:** OPEN

**Experiment status:** useful reduction / elementary partial lemma

## Statement

Let `1 <= n_1 < n_2 < ...` be arbitrary integers with one forbidden residue class `a_i (mod n_i)` for each modulus. Let `A` consist of integers `n` such that for every `i`, either `n < n_i` or `n` does not lie in the forbidden residue class modulo `n_i`. Must `A` have logarithmic density?

## Finite-truncation zero-limit lemma

For `k >= 1`, let

`A^(k) = N \ union_{i<=k} B_i`,

where `B_i = {n >= n_i : n == a_i (mod n_i)}`. Each `A^(k)` is eventually periodic, hence has a natural (and logarithmic) density `delta_k`. The sequence `delta_k` decreases, so `delta = lim_k delta_k` exists.

**Lemma.** If `delta = 0`, then the full set `A` has natural density `0` (therefore logarithmic density `0`).

**Proof.** For every fixed `k`, the full survivor set satisfies `A subset A^(k)`. Hence

`upper_density(A) <= density(A^(k)) = delta_k`.

Letting `k -> infinity` gives `upper_density(A) <= 0`. Since lower density is nonnegative, the natural density exists and equals `0`. QED.

Thus any unresolved instance capable of causing trouble must satisfy

`inf_k delta_k = delta > 0`.

This reduction does not solve the positive-limit case.

## Prior-art audit

The maintained Erdős Problems page still lists #25 as OPEN. A March 19, 2026 note by Przemyslaw Chojecki, *Truncated Congruence Sieves and Erdős Problem 25* (https://www.ulam.ai/research/erdos25.pdf), explicitly introduces the same finite-truncation densities `delta_k`, proves the summable-reciprocal and pairwise-coprime cases, and develops a first-kill/quotient-sieve reduction. Its pairwise-coprime divergent branch uses the same domination idea when the product density tends to zero. I did not find the fully general `delta=0` lemma stated separately in the audited note, but it is an immediate consequence of its setup and should not be treated as deep novelty without a broader literature check.

## Verification

The proof is purely order-theoretic once eventual periodicity of each finite truncation is established. No finite computation is involved.
