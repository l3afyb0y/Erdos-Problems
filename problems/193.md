# Erdős Problem #193

**Database status at attempt:** OPEN  
**Status checked:** 2026-08-30  
**Experiment result:** useful reformulation / adjacent block-sum obstruction; no complete progress

## Problem

Let \(S\subseteq\mathbb Z^3\) be finite and let \(a_1,a_2,\ldots\) be an infinite \(S\)-walk, so \(a_{i+1}-a_i\in S\). Must the visited set contain three collinear points?

Maintained source: https://www.erdosproblems.com/193

## Discovery record

Write the step word as

\[
s_i=a_{i+1}-a_i\in S.
\]

For every start \(i\) and length \(L\ge1\), define the block displacement

\[
D_i(L)=\sum_{r=0}^{L-1}s_{i+r}=a_{i+L}-a_i.
\]

Then

\[
a_i,\ a_{i+L},\ a_{i+2L}
\]

are collinear and equally spaced exactly when

\[
D_i(L)=D_{i+L}(L).
\]

Therefore any counterexample to #193 must satisfy the simultaneous additive-square avoidance condition

\[
\boxed{D_i(L)\ne D_{i+L}(L)\quad\text{for every }i,L\ge1.}
\]

In words: its finite-alphabet vector step word may never contain two adjacent blocks of equal length having the same vector sum.

This is only a necessary condition for avoiding all collinear triples: unequal adjacent block sums exclude equally-index-spaced collinear triples, but arbitrary collinear triples can occur with unequal index gaps. The converse is false in general, so the reduction cannot be promoted to an equivalence.

The scale recursion

\[
D_i(2L)=D_i(L)+D_{i+L}(L)
\]

was inspected as a possible finite-state contradiction. The avoidance condition only forces the two summands to be unequal; it does not force enough separation among the finitely many possible displacement vectors to close the argument in three dimensions.

## Prior-art / status audit

The maintained database still lists #193 as OPEN. Gerver and Ramsey proved the corresponding statement in \(\mathbb Z^2\), while the three-dimensional problem remains open; a 2025 comment records improved bounds on how many collinear points can be avoided but does not settle triples.

A post-attempt search also found the established literature on *additive-square-free words*, where adjacent equal-length equal-sum blocks are forbidden. That confirms this representation is part of a known neighboring framework rather than evidence of a new solution.

## Final classification

**useful reformulation / no complete progress**
