# Erdős Problem #217

**Database status at attempt:** OPEN  
**Attempt date:** 2026-08-30  
**Final classification:** candidate/new partial lemma — novelty unresolved / exact non-extendability of the published Palásti 8-point configuration

## Problem

For which integers `n` are there `n` points in the Euclidean plane, with no three collinear and no four concyclic, which determine exactly `n-1` distinct distances and whose distance multiplicities are exactly `1,2,...,n-1`?

The maintained Erdős Problems page was checked before discovery and still listed #217 as open. It records examples through `n=8` and no known example for `n>=9`.

Source: https://www.erdosproblems.com/217

## Unresolved quantifier

The original problem asks for the set of all admissible `n` (and Erdős conjectured that sufficiently large `n` are impossible). This run does **not** settle that global quantifier. It attacks the first unknown size by asking whether the standard published `n=8` configuration can reproduce itself by adjoining one new point.

## Discovery route

The published Palásti configuration has Cartesian coordinates

```text
(0,1), (sqrt(3),0), (2sqrt(3),0), (5sqrt(3)/2,5/2),
(3sqrt(3)/2,9/2), (sqrt(3)/2,7/2),
(3sqrt(3)/2,7/2), (sqrt(3),2).
```

Use coordinates `(u,v)` with physical point `(sqrt(3)u,v)`. Then squared Euclidean distance is

```text
3(u-u')^2 + (v-v')^2,
```

so all arithmetic for these eight points is rational. Their seven squared distances and multiplicities are

```text
1 -> 1
19 -> 2
21 -> 3
3 -> 4
4 -> 5
7 -> 6
13 -> 7.
```

### Closure question

**Suppose** a ninth distinct point `Q` could be adjoined while leaving the eight Palásti points fixed and producing a 9-point crescent configuration.

The old seven distance values remain present. A 9-point crescent configuration has exactly eight distance values total. **Therefore** the eight new edges from `Q` to the old points may introduce only one previously unseen distance value.

Because the original eight points have no four on a circle, no circle centered at `Q` can contain four of them. Hence any one value of `d(Q,P_i)` can occur at most three times. In particular, the single new distance can account for at most three of the eight new edges.

**Therefore at least five of the eight distances from `Q` to the old points must be old distance values.**

This converts an a priori continuous search into a finite exact search.

### Three-circle rationalization

Choose any three old points among those at old distance values from `Q`. The old configuration has no three collinear, so the three chosen centers are noncollinear.

For centers `P_i=(u_i,v_i)` and `P_j=(u_j,v_j)`, prescribed old squared distances `s,t` give

```text
3(u-u_i)^2 + (v-v_i)^2 = s,
3(u-u_j)^2 + (v-v_j)^2 = t.
```

Subtracting cancels the quadratic terms and leaves the rational line

```text
6(u_j-u_i)u + 2(v_j-v_i)v
 = s-t + 3(u_j^2-u_i^2) + (v_j^2-v_i^2).
```

Using a third noncollinear center gives a second nonparallel rational line. Thus every possible extension point is forced to a rational `(u,v)` obtained from three old centers and three choices from the seven old squared-distance values.

So the global one-point-extension question for this fixed 8-point configuration is reduced to finitely many exact rational candidates; there is no numerical approximation step in the verifier.

## Exact result

The verifier enumerates all

```text
C(8,3) * 7^3 = 19,208
```

three-center/radius assignments. After solving the two radical-axis equations and checking the absolute circle equations exactly, there are:

- `1163` satisfying assignment hits;
- `148` distinct rational candidate points;
- `46` candidates whose distances to at least five of the old points are among the old seven distance values;
- **zero distinct points** for which the complete 9-point distance histogram is `1,2,...,8`.

There is exactly one histogram hit if coincident points are allowed: `(u,v)=(3/2,9/2)`, which is already one of the eight Palásti points. Its apparent new multiplicity-one value is squared distance `0`, so it is inadmissible both because the points are not distinct and because `0` is not a distance between distinct points.

Hence:

> **Exact partial lemma.** The published Palásti 8-point planar crescent configuration cannot be extended to a 9-point crescent configuration by adjoining a single distinct point while retaining all eight old points.

The conclusion is stronger than a bounded lattice search: the added point was allowed to lie anywhere in the Euclidean plane.

## Adversarial checks

- The reduction uses only a **necessary** condition for an extension; it is not stated as an equivalence until the final full distance histogram is checked.
- The `at least five old-valued edges` step depends on the old configuration's no-four-concyclic property; the verifier checks that property exactly.
- Three-center reconstruction is valid because the chosen centers are noncollinear; the verifier also checks no three old points are collinear.
- Candidate coordinates are solved with `fractions.Fraction`; no floating-point tolerance is used.
- The full histogram is recomputed from all `36` pairs after adjoining each candidate, rather than inferred from the three seed constraints.
- Coincident candidates are explicitly rejected.
- This proves only non-extendability of this particular 8-point configuration. It does **not** prove that no 9-point crescent configuration exists, and it gives no hereditary obstruction for larger `n`.

## Prior-art audit

Post-discovery searches included the maintained Erdős Problems page, Burt–Goldstein–Manski–Miller–Palsson–Suh's *Crescent configurations* (arXiv:1509.07220), Durst–Hlavacek–Huynh–Miller–Palsson's classification work, the later normed-space crescent literature, targeted searches for `Palasti`, `one-point extension`, `n=9`, and recent agent/AI-assisted Erdős work.

The 2015 crescent paper reports an exhaustive search of a 91-point triangular-lattice region with no 9-point crescent configuration. That does not imply the present result: the candidate ninth point here ranges over the entire Euclidean plane, while the eight old points are fixed to Palásti's configuration.

No source located in this audit states the exact global non-extension result above. Search failure is not proof of novelty, so the classification remains **candidate/new partial lemma — novelty unresolved**.
