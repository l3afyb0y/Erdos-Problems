# Erdős Problem #148

**Database status at attempt (2026-08-30): OPEN.**

## Problem

Let \(F(k)\) count strictly increasing \(k\)-tuples of positive integers satisfying
\[
1=\frac1{n_1}+\cdots+\frac1{n_k}.
\]
Estimate \(F(k)\).

Current database record: https://www.erdosproblems.com/148

## Attempt

Two exact elementary constraints were isolated.

First, for every solution with \(k\ge2\),
\[
2\le n_1\le k,
\]
since \(n_1=1\) leaves no room for positive remaining summands and
\[
1<\frac{k}{n_1}
\]
would fail if \(n_1>k\). Thus the first denominator lies in a finite \(k-1\) point window, but the residual Egyptian-fraction problem after fixing \(n_1\) still has rapidly branching denominator ranges.

Second, the standard splitting identity
\[
\frac1n=\frac1{n+1}+\frac1{n(n+1)}
\]
can be applied to the largest denominator of any solution with largest denominator \(n>1\). Both new denominators are larger than every old denominator, are distinct, and the operation is injective because the largest new denominator \(n(n+1)\) determines \(n\). Hence
\[
F(k+1)\ge F(k)
\]
for every \(k\ge3\).

Iterating this single-branch splitting preserves injectivity but gives only one descendant per solution per extra term. Branching through more general unit-fraction splittings quickly creates collisions and admissibility constraints, and I did not obtain a family competitive with Konyagin's double-exponential lower-bound mechanism.

## Adversarial check

The identity above cannot be naively branched by splitting arbitrary denominators: newly introduced denominators can collide with existing ones, violating strict distinctness. Restricting the split to the current largest denominator avoids that error but leaves only the monotonicity injection.

## Prior-art / status audit

The maintained database still lists #148 open, with the current best bounds attributed to Konyagin and to Elsholtz--Planitzer. A July 2026 exact-computation report independently enumerated \(F(k)\) through \(k=7\). The elementary splitting map is standard and is not a frontier improvement.

**Final classification:** `known/basic reduction independently rediscovered / no progress beyond existing bounds`.
