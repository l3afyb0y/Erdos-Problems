# Erdős Problem 711

**Current status checked 2026-08-30:** OPEN (first question remains open; the second question has a 2026 affirmative result of van Doorn).

**Experiment status:** useful reformulation / no complete solution.

## Remaining open target

Let `f(n,m)` be minimal such that `(m,m+f(n,m))` contains distinct integers `x_1,...,x_n` with `k|x_k` for every `1<=k<=n`. Prove

`max_m f(n,m) <= n^(1+o(1))`.

## Exact interval-translation Hall system

For a proposed length `L`, let

`J_m(L)={m+1,...,m+L}`

and

`N_m(k)=J_m(L) intersect kZ`.

A simultaneous distinct assignment exists if and only if for every `S subset {1,...,n}`,

`|union_{k in S} N_m(k)| >= |S|`.

Thus the uniform-in-`m` problem asks for a length `L=n^(1+o(1))` for which **every translation** of the interval makes every divisibility-neighborhood union large enough.

## What translation changes

For each individual modulus `k`, translating an interval of fixed length `L` changes `|N_m(k)|` by at most one: it is always either `floor(L/k)` or `ceil(L/k)`. Therefore the difficulty cannot come from large fluctuations in single-modulus supply. It comes from correlation: a translation can make the candidate multiples of many different moduli coincide on the same positions.

This isolates the uniform problem as a simultaneous-collision problem rather than a pointwise divisor-count problem.

## Multiplicity identity

For a subset `S`, define the coverage multiplicity at a position `x` by

`r_S(x)=#{k in S : k|x}`.

Then

`sum_{x in J_m(L)} r_S(x) = sum_{k in S}|N_m(k)|`,

while Hall depends only on

`|{x:r_S(x)>0}|`.

Hence the loss from raw candidate supply to usable distinct positions is exactly

`sum_x (r_S(x)-1)_+`.

Any proof of the desired near-linear bound can therefore be phrased as a uniform statement that divisor-incidence redundancy cannot consume too much of the total candidate supply for any subset `S` and any translation `m`.

This identity is exact but does not by itself improve the known `n^(3/2)` upper scale.

## Prior-art audit

The maintained problem page remains OPEN because the first inequality is unresolved. van Doorn's 2026 paper settles the second question and is not being re-proved here. Public discussion notes connections to Kakeya-type incidence phenomena, consistent with the collision interpretation above. No complete proof of the remaining first question was found in the pre-attempt audit.

No novelty claim is made for the Hall reformulation or multiplicity identity.
