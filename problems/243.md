# Erdős Problem #243

**Database status at attempt:** OPEN (2026-08-30)

## Problem

Let \(1\le a_1<a_2<\cdots\) satisfy \(a_{n+1}/a_n^2\to1\) and \(\sum_n1/a_n\in\mathbb Q\). Must
\[
a_{n+1}=a_n^2-a_n+1
\]
for all sufficiently large \(n\)?

## Result

**Final label:** useful exact reformulation / no new global progress.

Define the integer recurrence defect
\[
\delta_n=a_{n+1}-(a_n^2-a_n+1).
\]
Then the elementary identity
\[
\frac1{a_n}
=\left(\frac1{a_n-1}-\frac1{a_{n+1}-1}\right)
-\frac{\delta_n}{a_n(a_n-1)(a_{n+1}-1)}
\]
holds exactly. Therefore for every starting index \(N\), using \(a_n\to\infty\),
\[
\sum_{n\ge N}\frac1{a_n}
=\frac1{a_N-1}
-\sum_{n\ge N}
\frac{\delta_n}{a_n(a_n-1)(a_{n+1}-1)}.
\]
Thus the Sylvester recurrence is precisely the zero-defect case in which the reciprocal tail telescopes to a single rational boundary term. Any counterexample with rational reciprocal sum must arrange exact rational cancellation in the weighted defect series despite \(\delta_n=o(a_n^2)\).

The branch was pushed through denominator-growth and first-nonzero-defect arguments, but the fixed rational denominator must be compared with least-common-multiple growth of the preceding \(a_i\), and the elementary estimates obtained here do not force a contradiction. This is the same global obstruction already visible in the Erdős–Straus criterion recorded on the database page.
