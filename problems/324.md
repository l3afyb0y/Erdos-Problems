# Erdős Problem 324

**Current database status checked 2026-08-30:** OPEN.

## Statement
Does there exist `f in Z[x]` such that all sums `f(a)+f(b)` with `0 <= a < b` are distinct?

Equivalently, the polynomial-value sequence is a Sidon sequence.

## Difference formulation
Once `f(n)` is strictly increasing (as any candidate with positive leading coefficient eventually is), the Sidon condition is equivalently uniqueness of positive differences:

`f(b)-f(a) = f(d)-f(c)` with `a<b`, `c<d`

must force `(a,b)=(c,d)`.

For a fixed input gap `h`,

`f(n+h)-f(n)`

is a polynomial in `n` of degree `deg(f)-1`. Thus a collision is an intersection between two such discrete difference-polynomial families corresponding to distinct gaps. This reformulation did not yield a uniform separation argument.

## Convexity check
If `f` is strictly convex on the relevant range and two pairs have the same input sum, then the more spread-out pair has the larger output sum. Hence a nontrivial collision cannot come merely from two different pairs with the same input sum. This removes one simple collision mechanism but does not control pairs with different input sums.

## Exact computation for the canonical fifth-power candidate
A direct hash search over every pair

`0 <= a < b <= 1500`

found no collision in `a^5+b^5`; this checks 1,125,750 pair sums exactly. This is finite evidence only and is far below what could establish the conjecture.

Known literature already rules out degrees at most 3, and the special quartic `x^4` is classically known not to work. No new degree obstruction or successful polynomial was obtained here.

## Classification
**No progress.** The difference-family viewpoint is natural but did not sharpen the known theory in this batch.
