# Erdős Problem 324

**Current database status checked 2026-08-30:** OPEN.

## Statement
Does there exist `f in Z[x]` such that all sums `f(a)+f(b)` with `0 <= a < b` are distinct?

Equivalently, the polynomial-value sequence has unique sums of two **distinct** indexed values.

## Difference formulation — corrected after reproduction audit
Once `f(n)` is strictly increasing (as any candidate with positive leading coefficient eventually is), uniqueness of **all** positive differences

`f(b)-f(a)` for `a<b`

is a stronger sufficient condition for the required distinct-two-sums property, but it is **not equivalent** to the formulation above. A repeated difference

`f(b)-f(a) = f(d)-f(c)`

rearranges to

`f(b)+f(c)=f(d)+f(a)`,

and gives a forbidden sum collision when both crossed pairs use distinct indices. But repeated adjacent differences can instead produce an equality involving a doubled term, which the problem's `a<b` formulation does not forbid. The elementary value set `{0,1,2}` is the smallest sanity check: its distinct-index sums are `1,2,3`, all different, while the positive difference `1` occurs twice.

Thus the difference-family viewpoint is useful only with this distinction kept explicit.

For a fixed input gap `h`,

`f(n+h)-f(n)`

is a polynomial in `n` of degree `deg(f)-1`. Intersections between two such discrete difference-polynomial families can create sum collisions when the associated crossed pairs are admissible. This reformulation did not yield a uniform separation argument.

## Convexity check
If `f` is strictly convex on the relevant range and two pairs have the same input sum, then the more spread-out pair has the larger output sum. Hence a nontrivial collision cannot come merely from two different pairs with the same input sum. This removes one simple collision mechanism but does not control pairs with different input sums.

## Exact computation for the canonical fifth-power candidate
A direct hash search over every pair

`0 <= a < b <= 1500`

found no collision in `a^5+b^5`; this checks 1,125,750 pair sums exactly. A fresh reproduction audit independently reran this exact search and again found no collision. This is finite evidence only and is far below what could establish the conjecture.

Known literature already rules out degrees at most 3, and the special quartic `x^4` is classically known not to work. No new degree obstruction or successful polynomial was obtained here.

## Classification
**No progress.** The original run's claim that distinct-two-sums was equivalent to uniqueness of all positive differences was incorrect and has been repaired. The finite fifth-power computation reproduced exactly, but no new mathematical frontier was reached.
