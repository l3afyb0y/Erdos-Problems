# Erdős Problem #17

**Database status at attempt:** OPEN

**Experiment status:** known reduction independently rediscovered

## Statement

Are there infinitely many cluster primes `p`, meaning primes for which every even `n <= p-3` is a difference of two primes not exceeding `p`?

## Terminal-interval consequence

Fix a cluster prime `p` and an integer `T` with `3 <= T <= p-2`. For each odd `t` in `[3,T]`, apply the cluster property to the even number `p-t`. If

`p-t = q_1-q_2`,

write `d=p-q_1`. Then `q_1=p-d` is prime, `q_2=t-d` is prime, and `0 <= d <= t-3 <= T-3`. Thus every odd `t <= T` is covered by a translate `d + (odd prime)`, with each admissible `d` corresponding to a prime in `[p-T,p]`.

Consequently the backward prime offsets from `p` form a finite additive complement to the odd primes on `[3,T]`. The crude counting consequence is that the number of primes in `[p-T,p]` is at least on the order of `T/pi(T)`, hence `>> log T`.

## Prior-art audit

This is known. A standard exercise based on the Blecksmith-Erdős-Selfridge theory states precisely that if `p` is a cluster prime then every terminal interval `[p-t,p]` contains `>> log t` primes. The live database still lists infinitude as OPEN, and modern summaries note the much stronger structural obstacles (including the preceding prime gap being at most six).

No novelty claim is made.
