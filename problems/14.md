# Erdős Problem 14

**Database status checked 2026-08-30:** OPEN.

**Experiment status:** `candidate/new partial lemma — novelty unresolved`

## Problem

Let `A subset N`, and let `B` be the set of positive integers which have exactly one unordered representation as `a+b` with `a,b in A` (allowing `a=b`). Write

`U(N) = |[1,N] \ B|`.

Can one have

`U(N) = o(sqrt(N))`?

## Candidate necessary asymptotic

**Lemma.** If `U(N)=o(sqrt(N))`, then necessarily

`A(N) := |A intersect [1,N]| ~ 2 sqrt(2/pi) sqrt(N)`.

Thus any positive construction for the problem is forced to have one specific square-root density constant; it cannot merely have arbitrary `Theta(sqrt N)` growth.

## Proof

Let `a=A(N)`. Consider all unordered pairs from `A intersect [1,N]`. Their number is

`C(a+1,2)`,

and every such pair has sum at most `2N`.

If a sum `s<=2N` is uniquely represented globally, then at most one of these pairs has sum `s`. If `s` is exceptional, then the number of unordered pairs from a set of `a` elements having fixed sum `s` is at most `ceil(a/2)`, because each first element determines its partner and the involution `x -> s-x` partitions the participating elements into pairs, with at most one diagonal fixed point.

Hence

`C(a+1,2) <= 2N + U(2N) ceil(a/2)`.

Since `U(2N)=o(sqrt N)`, the quadratic inequality implies

`A(N)=O(sqrt N)`.

Now let

`q(n) = #{(a,b) in A^2 : a+b=n}`

be the ordered representation function, and let

`Q(N)=sum_{n<=N} q(n)`.

For every nonexceptional `n`, `q(n)=2` unless its unique unordered representation is diagonal, in which case `q(n)=1`. There are at most `A(N/2)=O(sqrt N)` diagonal sums up to `N`.

For an exceptional `n<=N`, choosing the first coordinate determines the second, so

`q(n) <= A(N)=O(sqrt N)`.

There are `U(N)=o(sqrt N)` exceptional values. Consequently their total ordered-representation mass is

`sum_{n<=N, n exceptional} q(n) <= U(N) A(N) = o(N)`.

It follows that

`Q(N)=2N+o(N)`.

Put

`F(t)=sum_{a in A} exp(-ta)`.

Then

`F(t)^2 = sum_{n>=1} q(n) exp(-tn)`.

Abelian summation applied to `Q(N)~2N` gives

`F(t)^2 ~ 2/t`

as `t -> 0+`, and hence

`F(t) ~ sqrt(2) t^(-1/2)`.

Finally, Karamata's Tauberian theorem for Laplace-Stieltjes transforms of nonnegative measures gives

`A(N) ~ [sqrt(2)/Gamma(3/2)] sqrt(N)`.

Since `Gamma(3/2)=sqrt(pi)/2`, this is

`A(N) ~ 2 sqrt(2/pi) sqrt(N)`.

QED.

## Adversarial checks

The proof does **not** assume a uniform bound on the multiplicity of exceptional sums. That is the main danger in this problem. The preliminary quadratic inequality first establishes `A(N)=O(sqrt N)`; only then does `U(N)=o(sqrt N)` imply that all exceptional fibers together carry `o(N)` ordered pairs.

The diagonal contribution is only `O(sqrt N)`, so replacing unordered representations by ordered representations changes the first-order total by `o(N)`.

The Tauberian constant was checked independently from the continuous convolution: a limiting density `c x^{-1/2} dx` has self-convolution density `c^2 pi`; ordered representation density `2` therefore requires `c=sqrt(2/pi)`, whose counting function is `2c sqrt x = 2 sqrt(2/pi) sqrt x`.

This lemma does not decide existence. It supplies a necessary asymptotic under the conjectural `o(sqrt N)` exceptional regime.

## Prior-art audit

The maintained Erdős Problems page and a July 2026 computational/structural report still list the problem as OPEN. The latter explicitly identifies unbounded multiplicity on the exceptional fibers as the obstacle to transferring ordinary Sidon bounds. Targeted searches for the constant `2 sqrt(2/pi)` / `sqrt(8/pi)` in connection with Erdős Problem 14, unique sums, and representation functions did not locate this exact necessary asymptotic.

That search miss is not enough to certify novelty. The result is therefore recorded as **candidate/new partial lemma — novelty unresolved**, not as established new literature-level progress.
