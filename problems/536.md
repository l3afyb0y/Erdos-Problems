# Erdős Problem 536

**Database status checked 2026-08-30:** OPEN.

**Experiment classification:** candidate/new partial lemma — novelty unresolved.

## Problem

Let `f(N)` be the largest size of `A subset {1,...,N}` containing no three distinct `a,b,c` such that

`lcm(a,b)=lcm(a,c)=lcm(b,c)`.

Estimate `f(N)`; in particular, is `f(N)=o(N)`?

## Candidate improved upper bound

For every positive integer `N`,

`f(N) <= N - floor(N/6)`.

Hence

`f(N) <= (5/6+o(1))N`.

### Proof

Every positive integer is uniquely `r 2^i 3^j` with `gcd(r,6)=1`. Fix `r` and represent the members of `A` in this multiplicative fibre by exponent points `(i,j)`.

Suppose a selected point `(i,j)` has both a selected point `(i',j)` with `i'<i` and a selected point `(i,j')` with `j'<j`. The corresponding integers

`a=r 2^(i') 3^j`, `b=r 2^i 3^(j')`, `c=r 2^i 3^j`

are distinct and satisfy

`lcm(a,b)=lcm(a,c)=lcm(b,c)=c`,

which is forbidden. Therefore every selected point is either the leftmost selected point of its row or the bottommost selected point of its column.

If a fibre is nonempty, a selected point minimizing `i+j` is simultaneously row-leftmost and column-bottommost. Thus the size of the fibre is at most

`(# available rows) + (# available columns) - 1`.

Sum over all `r` coprime to `6`. The total number of available columns is exactly the number of integers at most `N` not divisible by `3`, namely `N-floor(N/3)`, because each column has a unique representative `r2^i`. The total number of available rows is the number of odd integers at most `N`, namely `N-floor(N/2)`, because each row has a unique representative `r3^j`. The number of ambient fibres is

`N-floor(N/2)-floor(N/3)+floor(N/6)`.

Therefore

`|A| <= (N-floor(N/3)) + (N-floor(N/2)) - (N-floor(N/2)-floor(N/3)+floor(N/6))`

`= N-floor(N/6)`.

## Verification

The corner identity is exact. A standalone checker exhaustively verifies all subsets for `N<=12`; independent mixed-integer optimization was also used during the audit through `N=20`, with every exact optimum satisfying the bound. The bound is not generally sharp (for example, the exact optimum at `N=15` is `12`, while the bound gives `13`).

## Prior-art audit

The maintained problem page currently records an upper bound `(221/225+o(1))N`. A May 2026 public note by Brian Saturnino gives the stronger `(43/48+o(1))N`. Since `5/6=40/48`, the argument above improves that public constant.

Targeted searches for `5/6`, `N-floor(N/6)`, and the row/column `2`-adic/`3`-adic fibre argument in connection with Erdős #536 did not locate an equivalent result. A search miss is not proof of novelty, so the classification remains **candidate/new partial lemma — novelty unresolved**.

This does not prove `f(N)=o(N)`.
