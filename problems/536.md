# Erdős Problem 536

**Database status checked 2026-08-30:** OPEN.

**Experiment classification:** candidate/new partial lemma — novelty unresolved.

## Problem

Let `f(N)` be the largest size of `A subset {1,...,N}` containing no three distinct `a,b,c` such that

`lcm(a,b)=lcm(a,c)=lcm(b,c)`.

Estimate `f(N)`; in particular, is `f(N)=o(N)`?

## First-pass bound

The first pass proved

`f(N) <= N - floor(N/6)`,

hence

`f(N) <= (5/6+o(1))N`.

The basic reason is that every integer is uniquely `r 2^i 3^j` with `gcd(r,6)=1`, and in each fixed `r`-fibre a selected exponent point `(i,j)` cannot simultaneously have a selected point strictly to its left in the same row and a selected point strictly below it in the same column. Otherwise those three integers have the same pairwise least common multiple.

The second, high-context pass noticed that the proof contains one more bit of state than the first pass used: **whether the fibre origin is selected.** Keeping that state makes the argument recursive.

## Strengthened fibre lemma

Let `D` be any finite down-set in `N^2` containing `(0,0)`, and let `F subset D` contain no triple

`(i',j), (i,j'), (i,j)`

with `i'<i` and `j'<j`.

Let `R` be the number of available rows of `D` and `C` the number of available columns.

Then

`|F| <= R + C - 2 + 1_F(0,0)`.

In words:

- if the origin is selected, `|F| <= R+C-1`;
- if the origin is not selected, `|F| <= R+C-2`.

### Proof

Every selected point is either the leftmost selected point of its row or the bottommost selected point of its column. If not, it has both a selected point to its left and a selected point below it, producing the forbidden corner triple.

If the origin is selected, it is simultaneously row-leftmost and column-bottommost, so counting row-leftmost and column-bottommost representatives gives at most `R+C-1` selected points.

Now suppose the origin is absent.

If some available row or some available column is unoccupied, then the same representative count already loses one additional slot and gives at most `R+C-2`.

Otherwise every available row and every available column is occupied. Since row `0` is occupied but `(0,0)` is not, its leftmost selected point has the form `(i,0)` with `i>0`; because it lies on the bottom row, it is also bottommost in its column. Likewise, since column `0` is occupied, its bottommost selected point has the form `(0,j)` with `j>0`; because it lies on the leftmost column, it is also leftmost in its row. These are two distinct points counted in both representative lists. Therefore the union of the row-leftmost and column-bottommost representatives has size at most `R+C-2`.

This proves the strengthened lemma.

## Recursive prime-pair inequality

Let `Q` be squarefree. Define

`U_Q(N) = {n <= N : gcd(n,Q)=1}`

and

`A_Q = A intersect U_Q(N)`.

Choose distinct primes `p,q` not dividing `Q`.

Every integer in `U_Q(N)` is uniquely

`r p^i q^j`

with `gcd(r,Qpq)=1`.

Apply the strengthened fibre lemma in every fixed `r`-fibre.

Let

`C_Q(N) = |U_Q(N)|`,

and

`C_{Q,p}(N) = #{n <= N : gcd(n,Q)=1 and p does not divide n}`.

Summing the fibre inequality gives the exact finite bound

`|A_Q| <= C_{Q,p}(N) + C_{Q,q}(N) - 2 C_{Qpq}(N) + |A_{Qpq}|`.

The last term is exactly the number of selected fibre origins: an origin is an integer coprime to `Qpq`.

For fixed `Q,p,q`, divide by `N` and let `N -> infinity`. Write

`d_Q = phi(Q)/Q`.

Then

`C_Q(N)/N -> d_Q`,

`C_{Q,p}(N)/N -> d_Q(1-1/p)`,

and

`C_{Qpq}(N)/N -> d_Q(1-1/p)(1-1/q)`.

Therefore

`limsup |A_Q|/N`

is at most

`d_Q(1/p + 1/q - 2/(pq)) + limsup |A_{Qpq}|/N`.

This can be iterated with disjoint prime pairs.

## General iterated bound

Take disjoint prime pairs

`(p_1,q_1), ..., (p_k,q_k)`

and put

`Q_0=1`,

`Q_j = product_{t<=j} p_t q_t`,

`d_j = phi(Q_j)/Q_j`.

After iterating the recursive inequality and finally using the trivial bound

`|A_{Q_k}| <= C_{Q_k}(N)`,

one obtains

`limsup_{N->infinity} f(N)/N`

`<= 1 - sum_{j=1}^k d_{j-1}/(p_j q_j)`.

The identity is telescoping: at step `j`, the ordinary drop from density `d_{j-1}` to `d_j` is larger than the fibre baseline by exactly `d_{j-1}/(p_jq_j)`, and that amount is saved permanently.

### First consequences

Using only `(2,3)` reproduces the first-pass bound

`5/6 = 0.833333...`.

Using `(2,3)` and then `(5,7)` gives

`1 - 1/6 - (1/3)(1/35)`

`= 173/210`

`= 0.8238095238...`.

Thus

`f(N) <= (173/210 + o(1)) N`.

Adding `(11,13)` gives

`f(N) <= (24691/30030 + o(1)) N`

`= (0.8222111222... + o(1))N`.

Adding further disjoint prime pairs continues to improve the constant, although this particular recursion appears to converge to a positive constant and therefore does **not** by itself prove `f(N)=o(N)`.

The value of the second pass is therefore not a solution of #536, but a stronger reusable recurrence: a missing core in one prime-pair fibre becomes the object passed to the next prime-pair stage instead of being discarded as an anonymous omission.

## Complete prose form

Fix two primes and sort every integer by everything except the powers of those two primes. Inside one such fibre, the selected exponent points cannot make a lower-left corner around a selected upper-right point. Therefore every selected point must be exposed from the left or from below.

The first proof counted one exposed point per row plus one per column and subtracted one overlap. But there are really two cases.

If the fibre's base integer is selected, one overlap is guaranteed.

If the base integer is absent, either a row or column is empty, or the bottom row and leftmost column each contain a different point exposed in both directions. Either way the fibre loses one more available slot.

So the amount of room left in a fibre depends on whether its base integer survives.

But the surviving base integers are exactly the integers with neither of the two chosen primes. They form another copy of the original problem after those primes are removed from consideration.

Therefore the remainder can be passed to another prime pair rather than bounded trivially. Repeating this gives the recursive inequality above.

## Verification

The earlier checker `verification/536_5over6.py` verifies the first-pass `5/6` bound on small cases.

A second checker,

[`../verification/536_recursive_prime_pairs.py`](../verification/536_recursive_prime_pairs.py),

computes the exact finite-`N` recursive count for arbitrary disjoint prime-pair sequences and brute-forces the true optimum for `N<=12`. It verifies, among other things,

- one pair gives asymptotic constant `5/6`;
- two pairs give `173/210`;
- three pairs give `24691/30030`;
- every exact optimum for `N<=12` lies below every corresponding recursive finite bound.

These finite checks are sanity checks only; the recursive theorem is the combinatorial argument above.
