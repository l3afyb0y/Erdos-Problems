# Erdős Problem 86

**Database status checked 2026-08-30:** OPEN.

**Experiment status:** `known reduction independently rediscovered`

## Problem

Let `f(n)=ex(Q_n,C4)`, where `Q_n` is the `n`-dimensional hypercube. Is

`f(n) <= (1/2+o(1)) n 2^(n-1)`?

## Product decomposition recovered in the attempt

Write

`Q_{n+m}=Q_n square Q_m`.

Let `H` be a `C4`-free subgraph of `Q_{n+m}`. For each fixed `m`-coordinate, the edges changing only an `n`-coordinate form a `C4`-free subgraph of `Q_n`, so the total number of such horizontal edges is at most

`2^m f(n)`.

Similarly, the total number of vertical edges is at most

`2^n f(m)`.

Therefore

`f(n+m) <= 2^m f(n) + 2^n f(m)`.

If

`rho_n = f(n)/(n 2^(n-1))`,

then

`(n+m) rho_{n+m} <= n rho_n + m rho_m`.

Thus `n rho_n` is subadditive, and Fekete's lemma implies existence of the corresponding normalized asymptotic infimum/limit along this weaker relation.

## Prior-art audit

This is not new. A standard double-counting argument gives the stronger fact that for every fixed cubical graph `H`,

`ex(Q_n,H)/|E(Q_n)|`

is non-increasing in `n`. In particular the normalized `C4`-free density already has a limit. The product-decomposition inequality is therefore a weaker rediscovery of known hypercube Turán-density infrastructure.

The actual Erdős #86 problem remains the determination that this limit is `1/2`; the best recorded upper bound on the maintained page is still above `0.6`, while explicit recent constructions concern lower bounds and do not settle the asymptotic conjecture.
