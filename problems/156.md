# Erdős Problem #156

**Database status at attempt:** OPEN (checked 2026-08-30)

**Final classification:** candidate/new partial lemma — novelty unresolved

## Statement

Does there exist a maximal Sidon set `A subset {1,...,N}` of size `O(N^(1/3))`?

Current status source: https://www.erdosproblems.com/156

The maintained record cites Ruzsa's construction of size `O((N log N)^(1/3))` and leaves removal of the logarithm open.

## Candidate exact lower bound for every maximal Sidon set

Let `A subset [1,N]` be maximal Sidon and put `m=|A|`. Then

\[
\boxed{m^3+m\ge 2N.}
\]

Equivalently,

\[
m\ge (2N)^{1/3}+O(N^{-1/3}).
\]

This is only a lower bound on the size of a maximal Sidon set, so it does **not** solve the existence problem.

## Proof

Because `A` is maximal, every `x in [1,N]\A` must create a repeated sum when adjoined to `A`. Since `A` itself is Sidon, every such collision is of one of exactly two forms:

1. `x+a=b+c` for some `a,b,c in A`; or
2. `2x=b+c` for some `b,c in A`.

For type 1, collisions with `a=b` or `a=c` give `x=c` or `x=b`, hence do not cover a point outside `A`. Thus only triples in which `a` is distinct from both members of the unordered pair `{b,c}` matter.

Count these triples. If `b<c`, there are `binom(m,2)` choices for `{b,c}` and `m-2` choices for `a`. If `b=c`, there are `m` choices for `b` and `m-1` choices for `a`. Hence the number of potentially outside values covered by type 1 is at most

\[
\binom m2(m-2)+m(m-1)
=\frac{m^2(m-1)}2.
\]

For type 2, the diagonal case `b=c` gives `x=b in A`, so only `b<c` can cover a point outside `A`. Thus type 2 covers at most

\[
\binom m2
\]

outside points.

Adding the `m` points of `A` itself,

\[
N\le m+\frac{m^2(m-1)}2+\frac{m(m-1)}2
=m+\frac{m(m-1)(m+1)}2
=\frac{m^3+m}{2}.
\]

Therefore `m^3+m>=2N`.

The argument is unaffected by overlaps among generated outside points: overlaps only decrease the number of distinct points covered, while the proof uses an upper bound on that number.

## Adversarial checks

The collision classification was checked directly from the Sidon definition. Degenerate triples were removed explicitly rather than counted as outside coverage. Exhaustive enumeration of all maximal Sidon subsets for `N<=12` found no violation of `m^3+m>=2N`.

A companion verifier is stored at `verification/156_maximal_lower.py`.

## Prior-art audit

Targeted searches for the exact inequality `m^3+m>=2N`, the constant `2^(1/3)`, and the `A+A-A` maximality count in the integer-interval problem did not locate this exact statement. Recent August 2026 work on #156 gives exact finite values much farther out but still states that the asymptotic problem and Ruzsa logarithm remain open. See:

- https://erdosproblemaday.com/day/156-maximal-sidon-log-factor
- https://oeis.org/A399118

Search failure is not evidence of novelty. The correct status is therefore **candidate/new partial lemma — novelty unresolved**.

## Bottom line

The candidate lemma sharpens the elementary cubic counting lower bound by keeping the diagonal/off-diagonal degeneracies exact, but it does not approach the missing upper construction `O(N^(1/3))`. Erdős #156 remains open.
