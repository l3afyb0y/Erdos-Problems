# Erdős Problem 40

**Database status checked 2026-08-30:** OPEN.

**Experiment status:** `no-progress / scale obstruction clarified`

## Problem

For which functions `g(N)->infinity` does

`A(N) := |A intersect [1,N]| >> sqrt(N)/g(N)`

force the additive representation function `1_A * 1_A(n)` to be unbounded?

## Attempt

Assume instead that the ordered representation function is bounded by a constant `K`. Then every ordered pair from `A intersect [1,N]` contributes to a sum at most `2N`, so

`A(N)^2 <= sum_{n<=2N} (1_A*1_A)(n) <= 2KN`.

Thus bounded representation forces only the Sidon-scale upper bound

`A(N) <= sqrt(2KN)`.

The hypothesis in Problem 40 deliberately sits below that scale by the diverging factor `g(N)`. Consequently no single-scale pair count can prove the desired conclusion: its lower and upper bounds remain compatible for every `g(N)->infinity`.

A dyadic cross-block version gives the same obstruction. If `U=A intersect [1,N]` and `V=A intersect (N,2N]`, then all ordered sums `u+v` lie in `[N+2,3N]`, and bounded representation gives

`|U||V| <= 2KN`.

Combining the assumed lower growth at `N` and `2N` does not contradict this when `g` diverges. A successful proof therefore needs genuinely multi-scale accumulation or arithmetic structure beyond pair-budget counting.

## Prior-art audit

The maintained problem page explicitly describes #40 as a stronger form of the still-open Erdős-Turán conjecture. The bounds above are elementary and do not improve the known frontier.
