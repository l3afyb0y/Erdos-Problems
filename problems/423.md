# Erdős Problem #423

**Database status at attempt:** OPEN (checked 2026-08-30)

## Problem

With `a_1=1`, `a_2=2`, let `a_k` be the least integer larger than `a_{k-1}` which is a sum of at least two consecutive earlier terms. Determine the asymptotic behaviour.

## Result

**Final classification:** useful exact state representation / no new asymptotic progress.

Let `S_j=a_1+...+a_j`. Every eligible consecutive block sum is a difference `S_j-S_i` with `j-i>=2`. Thus `a_{k+1}` is exactly the smallest element larger than `a_k` in the set of non-adjacent positive differences of the prefix sums `S_0,...,S_k`.

Equivalently, the process can be maintained by a priority queue of currently available interval sums; after selecting `a_k`, the only genuinely new candidates are the suffix sums ending at `a_k`. This recovers the efficient OEIS generation rule and makes clear why the complement count `a_n-n` is monotone.

A trivial but exact consequence is `a_{k+1} <= a_k+a_{k-1}`, since the last two terms form an eligible block. I did not convert the state representation into a near-linear upper bound or improve the current lower bounds for `a_n-n`.
