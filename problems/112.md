# Erdős Problem #112

**Database status at attempt:** OPEN (checked 2026-08-30 against current maintained Erdős-problem mirrors and the source repository).

## Statement

Let \(k(n,m)\) be the least integer \(N\) such that every directed graph on \(N\) vertices contains either an independent set of size \(n\) or a transitive tournament of size \(m\). Determine or estimate \(k(n,m)\).

## Exact recurrence rediscovered

Consider a directed graph \(G\) with neither an independent \(n\)-set nor a transitive \(m\)-tournament, and fix a vertex \(v\). Partition the remaining vertices by their relation to \(v\):

- \(N_0(v)\): vertices with no arc in either direction between them and \(v\);
- \(N_+(v)\): vertices \(u\) with an arc \(v\to u\);
- \(N_-(v)\): vertices \(u\) with an arc \(u\to v\).

(The last two sets may overlap when both arcs are present; only the union bound below is used.)

If \(|N_0(v)|\ge k(n-1,m)\), then inside \(N_0(v)\) there is either an independent set of size \(n-1\), which together with \(v\) gives an independent \(n\)-set, or a transitive \(m\)-tournament. Hence
\[
|N_0(v)|\le k(n-1,m)-1.
\]

If \(|N_+(v)|\ge k(n,m-1)\), then \(N_+(v)\) contains either an independent \(n\)-set or a transitive \((m-1)\)-tournament; in the latter case adjoining \(v\) at the beginning gives a transitive \(m\)-tournament. Thus
\[
|N_+(v)|\le k(n,m-1)-1.
\]
The same argument with reversed orientation gives
\[
|N_-(v)|\le k(n,m-1)-1.
\]

Since \(V(G)\setminus\{v\}\subseteq N_0(v)\cup N_+(v)\cup N_-(v)\),
\[
|G|-1\le k(n-1,m)+2k(n,m-1)-3.
\]
Therefore
\[
\boxed{k(n,m)\le k(n-1,m)+2k(n,m-1)-1.}
\]

For \(m=3\), using the elementary base \(k(n,2)=n\), this recurrence gives the familiar quadratic scale \(k(n,3)\le n^2+O(n)\) (with the precise initial convention determining lower-order constants).

## Adversarial check

The sets \(N_+\) and \(N_-\) need not be disjoint in a general directed graph, so treating them as a partition would be incorrect. The proof uses only a covering/union bound and remains valid with overlap. The recurrence is an upper bound only and does not determine the true asymptotic behavior.

## Prior-art note

Current references already record the Erdős--Rado polynomial upper bound \(O_m(n^{m-1})\) and the Larson--Mitchell quadratic bound in the \(m=3\) case. Thus the recurrence recovered here sits inside known Ramsey-style machinery and gives no improvement to the frontier.

## Final classification

**known reduction independently rediscovered / known polynomial-recursion barrier.**
