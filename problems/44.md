# Erdős Problem 44

**Database status checked 2026-08-30:** OPEN.

**Experiment status:** `useful reformulation / exact finite-seed compatibility criterion`

## Problem

Given a finite Sidon set `A subset [1,N]` and `epsilon>0`, can one find `M` and `B subset [N+1,M]` such that `A union B` is Sidon and

`|A union B| >= (1-epsilon)sqrt(M)`?

## Exact compatibility criterion once the new block is separated

Assume `B subset [2N+1,M]` and that `A` and `B` are individually Sidon. Then `A union B` is Sidon if and only if both of the following hold:

1. no nonzero positive difference occurring in `A` occurs in `B`, i.e. `Delta(A) intersect Delta(B)=empty`;
2. `(B+B-B) intersect A = empty`.

Here `Delta(S)={s-s': s>s', s,s' in S}`.

### Proof

Internal `A+A` and `B+B` collisions are already excluded by Sidonicity. Since every `b in B` exceeds `2N`, an `A+A` sum cannot equal an `A+B` or `B+B` sum, and a `B+B` sum cannot equal an `A+A` sum.

A collision between two mixed sums,

`a+b=a'+b'`,

with distinct pairs is equivalent to

`b-b'=a'-a`,

so such collisions are excluded exactly by the difference-set condition.

The only remaining collision type is

`b_1+b_2=a+b_3`,

which is equivalent to

`b_1+b_2-b_3=a`.

Thus the second condition excludes exactly the remaining mixed-vs-new collision type. Conversely, if both conditions hold, no collision type remains.

For a translate `B=t+S`, this becomes

`Delta(S) intersect Delta(A)=empty`

and

`(t+S+S-S) intersect A=empty`.

## Why this does not yet solve the problem

Putting a near-optimal finite Sidon set far enough to the right makes the second condition automatic but costs roughly a factor `1/sqrt(2)` in the final `sqrt(M)` constant. Reaching `1-epsilon` requires choosing a new block with only `o(M)` translational overhead while simultaneously avoiding the finite forbidden differences of `A` and the mixed three-term shadow `A-(S+S-S)`. The exact criterion isolates that remaining task but does not solve it.

## Prior-art audit

The maintained page still lists #44 open. Recent work disproved the stronger conjecture that every finite Sidon set embeds into a perfect difference set; that does not resolve this weaker asymptotic extension problem. A narrow search did not locate this exact separated-block iff criterion as a named lemma, but it is elementary and is recorded as a useful reformulation rather than claimed as major novelty.
