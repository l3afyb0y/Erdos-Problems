# Erdős Problem 32

**Current status checked 2026-08-30:** OPEN.

**Experiment status:** no progress / elementary coverage barrier.

## Statement

Find an additive complement `A` to the primes: every sufficiently large integer is `p+a` with `p` prime and `a in A`, with `A(N)=o((log N)^2)`; can one achieve `A(N)=O(log N)`?

## Coverage formulation

Fix a large dyadic target interval `[N,2N]`. Every target integer must be hit by at least one translate `a + primes`. Hence

`N <= sum_{a<=2N, a in A} #{p prime : N-a <= p <= 2N-a}`

up to the harmless finite exceptional range.

The language-first point is that an element `a` is not itself the useful object; its value is the number of target positions its prime translate covers. The problem is therefore an infinite set-cover problem with highly correlated prime-translate blocks.

## Elementary lower barrier

Uniformly in `a<=2N`, the number of primes in an interval of length at most `N` is at most `(1+o(1))N/log N` at this scale (using standard prime-counting upper bounds in the relevant ranges; very short boundary ranges only reduce coverage). Consequently the coverage inequality gives the crude necessary condition

`A(2N) >= (1-o(1)) log N`.

This recovers only the natural logarithmic scale, far weaker than Ruzsa's known constant-level lower result for the liminf. It does not decide whether `O(log N)` is achievable.

## Why the naive random construction stalls

If one independently selects a candidate shift `a` with probability on the order of `1/a`, then the expected counting function is logarithmic. But for a fixed large target `n`, the expected number of selected representations is heuristically

`sum_{p<n} const/(n-p)`,

which is only of constant order after averaging prime density. Thus an independent logarithmic-density random model leaves a positive probability of missing each target; it cannot simply be union-bounded over all large integers. The known `log^2`-scale random/covering heuristics correspond to increasing the local representation mass by an additional logarithm.

This is a barrier to a naive construction, not a proof that `O(log N)` is impossible; a successful logarithmic complement would need strong deterministic or correlated reuse.

## Prior-art audit

The maintained Erdős Problems page lists #32 as OPEN. It records Erdős's `O((log N)^2)` construction, almost-all improvements, and Ruzsa's lower bound `liminf A(N)/log N >= e^gamma`. No current complete proof or disproof of the `O(log N)` question was found in the pre-attempt audit.

No novelty claim is made for the coverage inequality.
