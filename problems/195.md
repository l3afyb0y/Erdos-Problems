# Erdős Problem #195

**Database status at attempt:** OPEN  
**Status checked:** 2026-08-30  
**Experiment result:** useful reformulation / order-type obstruction; no complete progress

## Problem

What is the largest \(k\) such that every permutation of \(\mathbb Z\) contains a monotone \(k\)-term arithmetic progression?

Maintained source: https://www.erdosproblems.com/195

## Discovery record

Let \(p(x)\in\mathbb Z\) be the position of the integer \(x\) in a doubly-infinite permutation. Avoiding a monotone 3-term arithmetic progression is exactly the condition that for every \(x\in\mathbb Z\) and \(d>0\),

\[
p(x+d)\notin (\min\{p(x),p(x+2d)\},\max\{p(x),p(x+2d)\}).
\]

Equivalently, along every arithmetic ray, consecutive comparison directions must alternate:

\[
\operatorname{sgn}(p(x+d)-p(x))
=-\operatorname{sgn}(p(x+2d)-p(x+d)).
\]

Thus a negative answer at length three is not merely a local pattern-avoidance problem. It asks for a total order satisfying all these simultaneous non-betweenness constraints **and** having order type exactly \(\mathbb Z\), so that it is realizable as a doubly-infinite permutation.

There are known chaotic linear orders of \(\mathbb Z\) with no monotone 3-term arithmetic progression. The recursive parity order is the model example: repeatedly separate the two parity children, and recurse after dividing by two. This satisfies the local non-betweenness constraints, but its limiting order has the wrong global order type (the standard construction has endpoints / non-discrete accumulation structure rather than order type \(\mathbb Z\)).

So the decisive missing quantifier is global:

> Can the simultaneous arithmetic non-betweenness constraints be realized by a **discrete, endpoint-free countable order with every element having finite interval distance to its neighbors**, i.e. an order isomorphic to \(\mathbb Z\)?

An end-extension attack was also tested. If a finite 3-AP-avoiding sequence \(P\) is extended on the right by \(x\), the only newly forbidden values are reflections \(x=2b-a\) of value-monotone ordered pairs \(a,b\in P\); left extension analogously forbids \(x=2a-b\). This gives a finite forbidden set at each one-sided extension step, but a prescribed missing integer can become forbidden at both ends, so the argument does not yield a back-and-forth construction enumerating all integers.

## Prior-art / status audit

The database remains OPEN. Geneson proved an upper bound \(k\le5\), and Adenwalla improved this to \(k\le4\). A current SciNet task explicitly identifies even the length-three guarantee/construction as a meaningful unresolved advance.

Ardal, Brown, and Jungić constructed chaotic linear orders avoiding monotone 3-APs in related settings; recent Lean work formalises such a chaotic order on \(\mathbb Z\). Those results reinforce that the unclosed point here is the required permutation order type, not the local arithmetic constraint itself.

## Final classification

**useful reformulation / order-type barrier; no complete progress**
