# Erdős Problem 708

**Current status checked 2026-08-30:** OPEN.

**Experiment status:** useful reformulation / no complete solution.

## Intended statement

Let `A` be an `n`-element set of integers at least 2 and put `M=max(A)`. For every interval `I` of `M` consecutive positive integers, ask for a small subset `B subset I` whose product is divisible by `prod(A)`. The published wording uses `|B|=g(n)`; a public discussion has already noted that the natural intended definition is a worst-case minimum size (equivalently `|B|<=g(n)`), which is the interpretation used here.

The conjectural target is `g(n) <= (2+o(1))n`, perhaps `g(n)<=2n`.

## Full-interval divisibility

For any interval

`I={t+1,...,t+M}`,

`prod(I) = M! * binom(t+M,M)`.

Hence `M! | prod(I)`. Since `A subset {2,...,M}` consists of distinct integers, `prod(A) | M!`. Therefore the entire interval always supplies enough prime-power valuation. The problem is purely a sparsification problem: delete almost all interval positions while retaining the valuation demand of `prod(A)`.

## Exact valuation-cover formulation

For every prime `p<=M`, set

`e_p = sum_{a in A} v_p(a)`.

Then the minimum admissible size of `B` is exactly the optimum of the finite 0-1 covering system

`min sum_{b in I} x_b`

subject to

`sum_{b in I} v_p(b) x_b >= e_p` for every prime `p<=M`,

with `x_b in {0,1}`.

Prime factors of interval elements larger than `M` are irrelevant. Thus the conjecture asks for a universal `2n+o(n)` sparsification theorem for these highly structured consecutive-integer valuation vectors.

## Language-first branch that fails

For each individual `a<=M`, the interval contains a multiple of `a`. It is tempting to assign one or two carrier integers to each source element `a` and then take the union of all carriers. The obstruction is multiplicity: if two source elements choose the same carrier, multiplying the union counts that carrier only once, whereas the two independent divisibility certificates may have used its prime valuations twice. Carrier sharing therefore helps cardinality but can destroy the valuation sum. A proof of `2n` needs a genuinely global allocation argument, not independent per-element certificates.

## Large-prime layer

If `p>sqrt(M)`, then every multiple of `p` in `{1,...,M}` has `p`-adic valuation exactly one, and the total target demand satisfies

`e_p <= floor(M/p)`.

Any interval of length `M` contains either `floor(M/p)` or `ceil(M/p)` multiples of `p`, so before sparsification the large-prime demand is met by a matching number of carrier positions. The remaining difficulty is simultaneous selection across different primes, because several prime demands can coexist in the same interval position.

This gives a clean layer decomposition but does not yield the required cardinality bound.

## Verification / prior art

The maintained Erdős Problems page lists #708 as OPEN and records the lower bound `g(n)>=(2-o(1))n` and `g(3)=4`. The public discussion already contains the wording issue noted above. No complete proof or disproof was found in the pre-attempt audit.
